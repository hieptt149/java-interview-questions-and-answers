# How to Implement Timeout for CompletableFuture? (Cách triển khai timeout cho CompletableFuture)

## 🟢 Junior Level

Trong Java 9+ có một phương thức tích hợp sẵn **`orTimeout()`**:

```java
CompletableFuture<String> cf = fetchDataAsync();

// Timeout 5 giây
cf.orTimeout(5, TimeUnit.SECONDS)
  .thenAccept(result -> System.out.println(result))
  .exceptionally(ex -> {
      if (ex instanceof TimeoutException) {
          System.out.println("Timeout!");
      }
      return "fallback";
  });
```

Đối với Java 8 — bạn có thể tự triển khai thủ công:
```java
public static <T> CompletableFuture<T> withTimeout(
    CompletableFuture<T> cf, long timeout, TimeUnit unit
) {
    CompletableFuture<T> timeoutCF = new CompletableFuture<>();

    // ⚠️ Lưu ý: ví dụ này tạo một ScheduledThreadPool mới ở mỗi lần gọi.
    // Trong production, dùng một scheduler chung duy nhất hoặc đừng quên scheduler.shutdown().
    ScheduledExecutorService scheduler = Executors.newScheduledThreadPool(1);
    scheduler.schedule(() ->
        timeoutCF.completeExceptionally(new TimeoutException()),
        timeout, unit
    );

    return CompletableFuture.anyOf(cf, timeoutCF)
        .thenApply(result -> (T) result);
}
```

## 🟡 Middle Level

### Các Phương Thức Java 9+

**orTimeout:**
```java
cf.orTimeout(5, TimeUnit.SECONDS)
  .exceptionally(ex -> {
      // TimeoutException
      return fallback;
  });
```

**completeOnTimeout:**
```java
// Khi timeout — giá trị fallback
cf.completeOnTimeout("default", 5, TimeUnit.SECONDS)
  .thenAccept(result -> System.out.println(result));
```

### Triển Khai Java 8

```java
public static <T> CompletableFuture<T> withTimeout(
    CompletableFuture<T> cf, long timeout, TimeUnit unit
) {
    CompletableFuture<T> result = new CompletableFuture<>();

    ScheduledExecutorService scheduler = Executors.newScheduledThreadPool(1);

    // Lập lịch timeout
    ScheduledFuture<?> timeoutFuture = scheduler.schedule(() -> {
        result.completeExceptionally(new TimeoutException());
    }, timeout, unit);

    // Hoàn thành bình thường
    cf.whenComplete((value, ex) -> {
        timeoutFuture.cancel(false);
        if (ex != null) {
            result.completeExceptionally(ex);
        } else {
            result.complete(value);
        }
    });

    return result;
}
```

### Các Lỗi Thường Gặp

1. **Không đóng scheduler:**
```java
// ❌ Scheduler không được đóng — memory leak
ScheduledExecutorService scheduler = Executors.newScheduledThreadPool(1);

// ✅ Đóng sau khi dùng
scheduler.shutdown();
```

## 🔴 Senior Level

### Triển Khai Nội Bộ

**orTimeout nội bộ:**
```java
// orTimeout đăng ký một handler whenComplete mà, khi hoàn thành
// bình thường, gọi scheduledFuture.cancel(false), hủy tác vụ đã lập lịch.
// Nếu timeout xảy ra trước — completeExceptionally(TimeoutException)
// hoàn thành CF, và chuỗi callback không còn thực thi.
```

### Edge Cases

**1. Timeout vs hủy:**
```java
cf.orTimeout(5, TimeUnit.SECONDS);

// Timeout KHÔNG hủy việc thực thi tác vụ!
// Tác vụ vẫn tiếp tục chạy ở background
// Chỉ có CF hoàn thành với TimeoutException
```

**2. Nhiều timeout:**
```java
// Timeout cuối cùng thắng (cái ngắn nhất kích hoạt trước)
cf.orTimeout(10, TimeUnit.SECONDS)
  .orTimeout(5, TimeUnit.SECONDS);  // cái này kích hoạt trước
```

### Kinh Nghiệm Production

**Service có khả năng phục hồi:**
```java
@Service
public class ResilientService {
    public CompletableFuture<Data> getData(String key) {
        return fetchDataAsync(key)
            .orTimeout(5, TimeUnit.SECONDS)
            .exceptionallyCompose(ex -> {
                if (ex instanceof TimeoutException) {
                    return getFromCacheAsync(key);
                }
                return CompletableFuture.failedFuture(ex);
            });
    }
}
```

### Best Practices

```java
// ✅ orTimeout cho Java 9+
cf.orTimeout(5, TimeUnit.SECONDS);

// ✅ completeOnTimeout cho fallback
cf.completeOnTimeout(defaultValue, 5, TimeUnit.SECONDS);

// ✅ Timeout tùy chỉnh cho Java 8
withTimeout(cf, 5, TimeUnit.SECONDS);

// ❌ Quên đóng scheduler
// ❌ Bỏ qua TimeoutException
```

## 🎯 Interview Cheat Sheet

**Cần phải biết:**
- orTimeout(timeout, unit) — Java 9+, hoàn thành CF với TimeoutException
- completeOnTimeout(value, timeout, unit) — Java 9+, giá trị fallback khi timeout
- Timeout KHÔNG hủy tác vụ — nó vẫn tiếp tục chạy ở background
- Java 8: ScheduledExecutorService + anyOf(cf, timeoutCF)
- Một scheduler chung cho tất cả timeout, không phải một scheduler mới mỗi lần gọi

**Các câu hỏi phụ thường gặp:**
- **orTimeout có hủy tác vụ không?** — Không, CF hoàn thành với TimeoutException, tác vụ vẫn tiếp tục làm việc
- **completeOnTimeout vs orTimeout?** — completeOnTimeout trả về một fallback, orTimeout ném ra một ngoại lệ
- **Timeout Java 8 không có ScheduledExecutor?** — Không có lựa chọn thay thế. ScheduledExecutorService là lựa chọn duy nhất
- **Nhiều timeout trên một CF?** — Cái cuối cùng (ngắn nhất) thắng

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- "orTimeout hủy việc thực thi tác vụ" — tác vụ vẫn tiếp tục làm việc
- "Tạo một ScheduledThreadPool mới cho mỗi timeout" — memory leak, cần một scheduler chung
- "TimeoutException không cần xử lý" — cần fallback hoặc retry
