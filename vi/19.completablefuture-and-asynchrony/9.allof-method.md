# What Does allOf() Method Do and When to Use It? (Phương thức allOf() làm gì và khi nào nên dùng)

## 🟢 Junior Level

**`allOf()`** — chờ **TẤT CẢ** các CompletableFuture được truyền vào hoàn thành và trả về một CompletableFuture mới.

```java
CompletableFuture<String> cf1 = CompletableFuture.supplyAsync(() -> "Hello");
CompletableFuture<String> cf2 = CompletableFuture.supplyAsync(() -> "World");
CompletableFuture<String> cf3 = CompletableFuture.supplyAsync(() -> "!");

// Chờ cả ba hoàn thành
CompletableFuture<Void> all = CompletableFuture.allOf(cf1, cf2, cf3);

all.thenRun(() -> {
    // Tất cả đã hoàn thành — bây giờ có thể lấy kết quả
    System.out.println(cf1.join() + " " + cf2.join() + " " + cf3.join());
    // Hello World !
});
```

**Quan trọng:** `allOf()` trả về `CompletableFuture<Void>` — nó không chứa kết quả, bạn cần gọi `join()` trên mỗi CF gốc.

## 🟡 Middle Level

### Cách Hoạt Động

```java
CompletableFuture<User> user = getUserAsync(userId);
CompletableFuture<Order> order = getOrderAsync(userId);
CompletableFuture<Preferences> prefs = getPrefsAsync(userId);

// Chờ tất cả
CompletableFuture<Void> all = CompletableFuture.allOf(user, order, prefs);

// Sau khi tất cả hoàn thành
all.thenRun(() -> {
    User u = user.join();    // không chặn — đã sẵn sàng
    Order o = order.join();
    Preferences p = prefs.join();

    process(new UserProfile(u, o, p));
});
```

### Xử Lý Lỗi

```java
// Nếu ít nhất một CF thất bại — allOf cũng sẽ thất bại
CompletableFuture.allOf(cf1, cf2, cf3)
    .exceptionally(ex -> {
        // ex — CompletionException với cause
        log.error("One of the CFs failed", ex);
        return null;
    });
```

### Các Lỗi Thường Gặp

1. **Cố gắng lấy kết quả từ allOf:**
```java
// ❌ allOf trả về Void!
CompletableFuture<String> all = CompletableFuture.allOf(cf1, cf2);
// all.join();  // null!

// ✅ Cần join trên mỗi CF
CompletableFuture.allOf(cf1, cf2).thenRun(() -> {
    String r1 = cf1.join();
    String r2 = cf2.join();
});
```

## 🔴 Senior Level

### Triển Khai Nội Bộ

```java
// Nội bộ allOf tạo một cây dependency và hoàn thành
// khi tất cả CF được truyền vào đã xong. Tên class nội bộ thực tế của JDK
// khác nhau — đây là một mô tả khái niệm.
```

### Đánh Đổi Kiến Trúc

| allOf()                    | thenCombine()         |
| -------------------------- | ---------------------- |
| Nhiều CF (2+)              | Hai CF               |
| Trả về Void               | Trả về kết quả        |
| Cần join cho kết quả      | Kết quả trong callback   |

### Edge Cases

**1. Pattern thu thập kết quả:**
```java
public CompletableFuture<List<User>> getUsers(List<Long> ids) {
    List<CompletableFuture<User>> futures = ids.stream()
        .map(id -> getUserAsync(id))
        .toList();

    return CompletableFuture.allOf(futures.toArray(new CompletableFuture[0]))
        .thenApply(v ->
            futures.stream()
                .map(CompletableFuture::join)
                .toList()
        );
}
```

**2. Kết quả một phần với timeout:**
```java
CompletableFuture<Void> all = CompletableFuture.allOf(cf1, cf2, cf3);

all.orTimeout(5, TimeUnit.SECONDS)
   .exceptionally(ex -> {
       // Timeout hoặc lỗi
       // Nhưng một số CF có thể đã hoàn thành
       if (cf1.isDone()) System.out.println("cf1 done");
       if (cf2.isDone()) System.out.println("cf2 done");
       return null;
   });
```

### Hiệu Năng

```
allOf():
- Tạo: ~10 ns
- Overhead mỗi CF: ~5 ns
- Đối với N CF — cây độ sâu log(N)

join() trên một CF đã sẵn sàng: ~1 ns (không chặn)
```

### Kinh Nghiệm Production

**Lời gọi API theo batch:**
```java
@Service
public class DashboardService {
    public CompletableFuture<Dashboard> getDashboard(Long userId) {
        CompletableFuture<User> user = userService.findByIdAsync(userId);
        CompletableFuture<List<Order>> orders = orderService.findByUserIdAsync(userId);
        CompletableFuture<List<Notification>> notifications =
            notificationService.findByUserIdAsync(userId);
        CompletableFuture<Stats> stats = statsService.getStatsAsync(userId);

        return CompletableFuture.allOf(user, orders, notifications, stats)
            .thenApply(v -> new Dashboard(
                user.join(),
                orders.join(),
                notifications.join(),
                stats.join()
            ));
    }
}
```

### Best Practices

```java
// ✅ allOf cho các lời gọi song song độc lập
CompletableFuture.allOf(cf1, cf2, cf3)
    .thenRun(() -> combine(cf1.join(), cf2.join(), cf3.join()));

// ✅ Xử lý lỗi
CompletableFuture.allOf(cf1, cf2)
    .exceptionally(ex -> handleErrors(ex, cf1, cf2));

// ❌ allOf khi cần tuần tự
// ❌ Bỏ qua việc allOf trả về Void
```

### Khi Nào KHÔNG Nên Dùng allOf

- **Cần kết quả ngay khi chúng sẵn sàng** — xử lý mỗi CF riêng biệt
- **Một lỗi không nên hủy các cái còn lại** — allOf ném ra lỗi ngay khi lỗi đầu tiên xảy ra

```java
// ❌ allOf — một lỗi làm sập tất cả
CompletableFuture.allOf(cf1, cf2, cf3)
    .exceptionally(ex -> null);  // tất cả kết quả bị mất

// ✅ Xử lý mỗi CF riêng biệt
cf1.handle((r, ex) -> ex != null ? fallback1 : r);
cf2.handle((r, ex) -> ex != null ? fallback2 : r);
cf3.handle((r, ex) -> ex != null ? fallback3 : r);
```

## 🎯 Interview Cheat Sheet

**Cần phải biết:**
- allOf() nhận N CompletableFuture, trả về CompletableFuture<Void>
- Hoàn thành khi TẤT CẢ CF đã xong, hoặc khi lỗi đầu tiên xảy ra
- Để lấy kết quả, gọi join() trên mỗi CF gốc
- Độ trễ = max(tất cả CF) — tất cả thực thi song song
- Pattern allAsList: allOf + stream.map(CompletableFuture::join).toList()

**Các câu hỏi phụ thường gặp:**
- **allOf có trả về kết quả không?** — Không, Void. join() trên mỗi CF riêng biệt
- **Điều gì xảy ra nếu một CF thất bại?** — allOf hoàn thành với một CompletionException
- **allOf có chặn không?** — Không, nó trả về một CF. allOf().join() mới chặn
- **Cách lấy kết quả một phần khi có lỗi?** — Kiểm tra isDone() trên mỗi CF

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- "allOf trả về một mảng kết quả" — nó trả về Void
- "allOf tiếp tục khi một CF thất bại" — nó hoàn thành với một lỗi
- "allOf().join() không chặn" — join() chặn cho đến khi hoàn thành
