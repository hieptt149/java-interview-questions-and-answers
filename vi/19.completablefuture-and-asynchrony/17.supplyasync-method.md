# What Does supplyAsync() Method Do and When to Use It? (Phương thức supplyAsync() làm gì và khi nào nên dùng)

## 🟢 Junior Level

**`supplyAsync()`** — tạo một CompletableFuture thực thi một tác vụ **bất đồng bộ** và **trả về một kết quả**.

```java
// supplyAsync — tác vụ có giá trị trả về
CompletableFuture<String> cf = CompletableFuture.supplyAsync(() -> {
    // Chạy trong thread khác
    return "Hello from async";
});

// Lấy kết quả
cf.thenAccept(result -> System.out.println(result));
```

**Khác biệt so với `runAsync()`:**
- `supplyAsync()` — trả về một giá trị (`Supplier<T>`)
- `runAsync()` — không trả về (`Runnable`)

```java
// supplyAsync — có kết quả
CompletableFuture<String> cf1 = CompletableFuture.supplyAsync(() -> "result");

// runAsync — không có kết quả
CompletableFuture<Void> cf2 = CompletableFuture.runAsync(() -> {
    System.out.println("Done");
});
```

## 🟡 Middle Level

### Khi Nào Nên Dùng

**supplyAsync:**
```java
// Khi bạn cần một kết quả
CompletableFuture<User> user = CompletableFuture.supplyAsync(() -> {
    return userRepository.findById(userId);
});

CompletableFuture<String> data = CompletableFuture.supplyAsync(() -> {
    return httpClient.get(url);
});
```

**Với Executor tùy chỉnh:**
```java
ExecutorService ioExecutor = Executors.newFixedThreadPool(10);

CompletableFuture<String> cf = CompletableFuture.supplyAsync(() -> {
    return httpClient.get(url);
}, ioExecutor);
```

### Các Lỗi Thường Gặp

1. **Chặn trong commonPool:**
```java
// ❌ Chặn ForkJoinPool
CompletableFuture.supplyAsync(() -> {
    return httpClient.get(url);  // I/O chặn
});

// ✅ Executor tùy chỉnh
CompletableFuture.supplyAsync(() -> httpClient.get(url), ioExecutor);
```

### Khi Nào KHÔNG Nên Dùng supplyAsync

- **Các thao tác đồng bộ đơn giản** — overhead tạo CF không đáng
- **Thứ tự thực thi nghiêm ngặt** — dùng các lời gọi tuần tự
- **Cần hủy với ngắt (interruption)** — tốt hơn nên dùng FutureTask

## 🔴 Senior Level

### Triển Khai Nội Bộ

```java
public static <U> CompletableFuture<U> supplyAsync(Supplier<U> supplier) {
    return asyncSupplyStage(asyncPool, supplier);
}

public static <U> CompletableFuture<U> supplyAsync(
    Supplier<U> supplier, Executor executor
) {
    return asyncSupplyStage(screenExecutor(executor), supplier);
}

// asyncPool = ForkJoinPool.commonPool()
// Tạo một CompletableFuture và lập lịch tác vụ trong executor
// Biểu diễn pseudocode đơn giản hóa. Tên phương thức JDK thực tế khác nhau.
```

### Đánh Đổi Kiến Trúc

| supplyAsync      | runAsync         |
| ---------------- | ---------------- |
| Trả về T        | Trả về Void     |
| Supplier<T>      | Runnable         |
| Cho tính toán | Cho side effect |

### Edge Cases

**1. Ngoại lệ trong supplier:**
```java
CompletableFuture.supplyAsync(() -> {
    throw new RuntimeException("Error");
}).exceptionally(ex -> "recovered");
```

**2. Tác vụ chạy dài:**
```java
// ❌ Tác vụ dài trong commonPool
CompletableFuture.supplyAsync(() -> {
    Thread.sleep(60000);  // chặn 60 giây
    return result;
});

// ✅ Executor tùy chỉnh
CompletableFuture.supplyAsync(longTask, longTaskExecutor);
```

### Hiệu Năng

```
supplyAsync():
- Tạo: ~10 ns
- Lập lịch: ~1μs
- Chuyển thread: ~1-5μs

Overhead commonPool: tối thiểu
Executor tùy chỉnh: + overhead hàng đợi
```

### Kinh Nghiệm Production

```java
@Service
public class OrderService {
    private final ExecutorService ioExecutor;

    public CompletableFuture<Order> getOrderAsync(Long id) {
        return CompletableFuture.supplyAsync(() -> {
            return orderRepository.findById(id);
        }, ioExecutor);
    }

    // Kết hợp
    public CompletableFuture<OrderSummary> getSummaryAsync(Long id) {
        CompletableFuture<Order> order = getOrderAsync(id);
        CompletableFuture<User> user = getUserAsync(id);

        return order.thenCombine(user, (o, u) ->
            new OrderSummary(o, u)
        );
    }
}
```

### Best Practices

```java
// ✅ supplyAsync cho tính toán
CompletableFuture.supplyAsync(() -> calculate());

// ✅ Executor tùy chỉnh cho I/O
CompletableFuture.supplyAsync(ioTask, ioExecutor);

// ✅ Virtual Threads (Java 21+)
CompletableFuture.supplyAsync(task, vThreads);

// ❌ Chặn trong commonPool
// ❌ Tác vụ dài không có Executor tùy chỉnh
```

## 🎯 Interview Cheat Sheet

**Cần phải biết:**
- supplyAsync(Supplier<T>) — tác vụ bất đồng bộ trả về một kết quả
- runAsync(Runnable) — tác vụ bất đồng bộ không có giá trị trả về (Void)
- Không có Executor: ForkJoinPool.commonPool(), có Executor: pool được chỉ định
- Đối với I/O, luôn truyền Executor riêng của bạn
- supplyAsync cho tính toán và thao tác fetch, runAsync cho side effect

**Các câu hỏi phụ thường gặp:**
- **supplyAsync vs runAsync — khi nào dùng cái nào?** — supplyAsync khi bạn cần một kết quả (Supplier<T>), runAsync khi không (Runnable)
- **supplyAsync không có Executor — pool nào?** — ForkJoinPool.commonPool(), đối với I/O điều này dẫn đến thread pool starvation
- **Ngoại lệ trong supplier — điều gì xảy ra?** — CF hoàn thành với CompletionException, cần exceptionally/handle
- **supplyAsync vs thenApplyAsync?** — supplyAsync tạo một CF mới, thenApplyAsync biến đổi một CF hiện có

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- "supplyAsync và runAsync giống nhau" — supplyAsync trả về T, runAsync trả về Void
- "supplyAsync không có Executor an toàn cho HTTP" — I/O chặn trong commonPool → starvation
- "supplyAsync tạo một thread mới" — nó dùng ForkJoinPool.commonPool() hoặc Executor được chỉ định
