# What Is Recursive Type Bound? (Recursive type bound là gì)

## 🟢 Junior Level

**Recursive type bound** — khi một type parameter được ràng buộc bởi **chính nó** hoặc bởi một kiểu cũng dùng chính tham số này.

```java
// T phải là Comparable với chính nó
public class SortedList<T extends Comparable<T>> {
    private List<T> list = new ArrayList<>();

    public void add(T item) {
        list.add(item);
        list.sort(Comparable::compareTo);
    }
}

SortedList<Integer> ints = new SortedList<>();    // ✅ Integer triển khai Comparable<Integer>
SortedList<String> strings = new SortedList<>();  // ✅ String triển khai Comparable<String>
```

**Analogy đơn giản:** "Tôi có thể so sánh chính mình với những người giống tôi"

## 🟡 Middle Level

### Cách Hoạt Động

**Ví dụ kinh điển — Enum:**
```java
// Khai báo Enum của Java
public abstract class Enum<E extends Enum<E>>
    implements Comparable<E> {

    public final int compareTo(E other) {
        return this.ordinal - other.ordinal;
    }
}

// Sử dụng
enum Color { RED, GREEN, BLUE }
// Color extends Enum<Color>
// Color implements Comparable<Color>
```

**Tại sao cần thiết:**
```java
// Không có recursive bound — không thể đảm bảo tính an toàn kiểu
public class Box<T extends Comparable<T>> {
    private T value;

    public int compare(T other) {
        return value.compareTo(other);  // ✅ an toàn kiểu
    }
}

Box<Integer> box = new Box<>();
box.compare(42);  // OK

// Box<Object> box2 = new Box<>();  // ❌ Object không triển khai Comparable<Object>
```

### Kiểu Tự Ràng Buộc (Self-bounding Types)

**Pattern cho fluent interface:**
```java
public abstract class Builder<T, B extends Builder<T, B>> {
    protected abstract B self();

    public B withName(String name) {
        // ... thiết lập
        return self();
    }

    public B withAge(int age) {
        // ... thiết lập
        return self();
    }

    public T build() {
        // ... xây dựng
    }
}

public class UserBuilder extends Builder<User, UserBuilder> {
    @Override
    protected UserBuilder self() { return this; }
}

// Fluent API
User user = new UserBuilder()
    .withName("John")
    .withAge(25)
    .build();
```

### Các Lỗi Thường Gặp

1. **Recursive bound sai:**
```java
// ❌ T extends Comparable<Object> — không phải đệ quy
public class BadBox<T extends Comparable<Object>> { }

// ✅ T extends Comparable<T> — đệ quy
public class GoodBox<T extends Comparable<T>> { }
```

2. **Bound quá nghiêm ngặt:**
```java
// ❌ T phải chính xác là Comparable<T>
public class Box<T extends Comparable<T>> { }

// ⚠️ Sẽ không hoạt động cho một số kiểu
// Một số class triển khai Comparable với một supertype
```

## 🔴 Senior Level

### Triển Khai Nội Bộ

**Type erasure với recursive bound:**
```java
public class Box<T extends Comparable<T>> {
    private T value;
}

// Sau erasure: T -> Comparable (bound đầu tiên)
public class Box {
    private Comparable value;
}
```

**Recursive bound lồng nhau:**
```java
// Trường hợp phức tạp — Enum<E extends Enum<E>>
// T phải là Enum<T>
// Enum<T> triển khai Comparable<T>
// Do đó T triển khai Comparable<T>

public class Enum<E extends Enum<E>> implements Comparable<E> {
    // E — kiểu enum cụ thể
    // compareTo nhận cùng kiểu enum đó
}
```

### Đánh Đổi Kiến Trúc

**Recursive bound so với thông thường:**

| Đệ quy           | Thông thường                 |
| ------------------- | ----------------------- |
| So sánh an toàn kiểu| Có thể kém chính xác hơn     |
| Fluent interface   | Đơn giản hơn                 |
| Khó hiểu hơn| Dễ hơn                  |

### Edge Cases

**1. Nhiều recursive bound:**
```java
public class Graph<N extends Node<N, E>, E extends Edge<N, E>> {
    private List<N> nodes;
    private List<E> edges;
}

public interface Node<N extends Node<N, E>, E extends Edge<N, E>> {
    List<E> getEdges();
}

public interface Edge<N extends Node<N, E>, E extends Edge<N, E>> {
    N getSource();
    N getTarget();
}
```

**2. Recursive bound nới lỏng:**
```java
// T phải là Comparable với một supertype của T
public class SortedList<T extends Comparable<? super T>> {
    // Điều này nới lỏng bound — cho phép các lớp con cũng hoạt động
}

// ? super T cần thiết vì các lớp con kế thừa Comparable<SuperType>.
// Ví dụ, Dog extends Animal implements Comparable<Animal>.
// Không có ? super T, Dog sẽ không thỏa mãn Comparable<Dog>.

// Ví dụ:
class Date implements Comparable<Date> { }
class java.sql.Date extends Date { }
// java.sql.Date triển khai Comparable<Date> (qua kế thừa)
// Nhưng không phải Comparable<java.sql.Date>
// Với ? super T — nó hoạt động!
```

**3. CRTP (Curiously Recurring Template Pattern):**
```java
// Sử dụng thực tế: Enum<E extends Enum<E>> — mỗi kiểu enum
// chỉ so sánh với chính nó. Điều này đảm bảo compareTo an toàn kiểu.

// Pattern từ C++, được điều chỉnh cho Java
public abstract class SelfComparable<T extends SelfComparable<T>>
    implements Comparable<T> {

    public abstract int compareTo(T other);
}

public class MyType extends SelfComparable<MyType> {
    private int value;

    @Override
    public int compareTo(MyType other) {
        return Integer.compare(this.value, other.value);
    }
}
```

### Hiệu Năng

```
Recursive bound:
- Runtime: Overhead bằng không
- Thời gian biên dịch: kiểm tra phức tạp
- Type erasure: bound trở thành kiểu

Hiệu năng giống nhau cho tất cả các loại bound
```

### Kinh Nghiệm Production

**Ví dụ từ JDK:**
```java
// Enum — recursive bound kinh điển
public abstract class Enum<E extends Enum<E>>
    implements Comparable<E> { }

// Collections.max
public static <T extends Object & Comparable<? super T>> T max(
    Collection<? extends T> coll
) { }

// Pattern Builder
public abstract class AbstractQueryBuilder<B extends AbstractQueryBuilder<B>> {
    protected abstract B self();

    public B where(String condition) {
        // ...
        return self();
    }
}
```

**Ví dụ thực tế:**
```java
// Entity với self-type cho builder
public abstract class BaseEntity<E extends BaseEntity<E>> {
    private Long id;

    @SuppressWarnings("unchecked")
    public E withId(Long id) {
        this.id = id;
        return (E) this;
    }
}

public class User extends BaseEntity<User> {
    private String name;

    public User withName(String name) {
        this.name = name;
        return this;
    }
}

User user = new User()
    .withId(1L)
    .withName("John");
```

### Best Practices

```java
// ✅ Recursive bound cho so sánh
public class SortedList<T extends Comparable<T>> { }

// ✅ Bound nới lỏng cho lớp con
public class SortedList<T extends Comparable<? super T>> { }

// ✅ Self-bounding cho fluent API
public abstract class Builder<B extends Builder<B>> {
    protected abstract B self();
}

// ❌ Recursive bound quá phức tạp
// ❌ Recursive bound không cần thiết
```

## 🎯 Interview Cheat Sheet

**Cần phải biết:**
- Recursive type bound: `<T extends Comparable<T>>` — kiểu được ràng buộc bởi chính nó
- Ví dụ kinh điển — `Enum<E extends Enum<E>>` — mỗi enum so sánh với chính nó
- Kiểu tự ràng buộc cho fluent API: `Builder<B extends Builder<B>>` trả về `B`
- Recursive bound nới lỏng: `<T extends Comparable<? super T>>` — cho phép lớp con
- CRTP (Curiously Recurring Template Pattern) — pattern từ C++, được điều chỉnh cho Java
- Type erasure: `T extends Comparable<T>` -> erasure = Comparable

**Các câu hỏi phụ thường gặp:**
- **Tại sao cần recursive bound?** — Đảm bảo so sánh an toàn kiểu: T so sánh với T, không phải với Object
- **Tại sao Enum dùng recursive bound?** — Để `Color.compareTo(Color)` nhận Color, không phải Enum
- **Recursive bound nới lỏng là gì?** — `? super T` cho phép lớp con kế thừa Comparable<SuperType>
- **Self-bounding được dùng ở đâu?** — Pattern fluent builder: `withName().withAge().build()`

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- ❌ "Recursive bound tạo đệ quy vô hạn" — Đó là một ràng buộc compile-time, không phải runtime
- ❌ "Enum<E extends Enum<E>> là một điều kỳ quặc của Java" — Nó đảm bảo compareTo an toàn kiểu
- ❌ "Self-bounding chỉ dành cho builder" — Cũng cho node đồ thị, entity, comparable
- ❌ "Bound nới lỏng kém an toàn hơn" — `? super T` an toàn hơn, cho phép nhiều kiểu hơn
