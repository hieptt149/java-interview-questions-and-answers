# What does ExecutorService do? (ExecutorService làm gì?)

---

## Junior Level

### Hiểu biết cơ bản

`ExecutorService` là interface chính trong Java để quản lý các thread pool và thực thi các tác vụ bất đồng bộ.

**Không có ExecutorService:** bạn tự tạo thread thủ công (`new Thread().start()`), kiểm soát vòng đời của chúng, và xử lý lỗi. **Có ExecutorService:** bạn chỉ submit các tác vụ và nhận kết quả — framework quản lý thread cho bạn. Nó tách "làm gì" (tác vụ) khỏi "làm như thế nào và khi nào" (cơ chế thực thi).

### Ví dụ đơn giản

```java
// Tạo ExecutorService
ExecutorService executor = Executors.newFixedThreadPool(3);

// Submit một tác vụ
executor.submit(() -> {
    System.out.println("Task executed!");
});

// Tắt
executor.shutdown();
```

### Các cách chính để submit tác vụ

| Method                | Trả về     | Exception                                                                                                                                                               | Khi nào dùng               |
| --------------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------- |
| `execute(Runnable)`   | void       | In ra console                                                                                                                                                          | "Fire and forget"          |
| `submit(Runnable)`    | Future<?>  | Được bọc trong **ExecutionException** — wrapper cần để phân biệt lỗi tác vụ với lỗi ExecutorService. Exception gốc có sẵn qua `e.getCause()`.                            | Cần theo dõi việc hoàn thành|
| `submit(Callable<T>)` | Future<T>  | Được bọc trong **ExecutionException** — wrapper cần để phân biệt lỗi tác vụ với lỗi ExecutorService. Exception gốc có sẵn qua `e.getCause()`.                            | Cần một kết quả            |

### execute() vs submit()

```java
// execute() — "fire and forget"
executor.execute(() -> {
    System.out.println("Running...");
    // Lỗi ở đây — chỉ in ra System.err
});

// submit() — có thể lấy kết quả và lỗi
Future<?> future = executor.submit(() -> {
    System.out.println("Running...");
    // Lỗi ở đây — sẽ nằm trong future.get()
});

// Kiểm tra việc hoàn thành
if (future.isDone()) {
    System.out.println("Task completed");
}
```

### Tắt Pool

```java
// Cách 1: Graceful shutdown
executor.shutdown(); // Ngừng nhận các tác vụ mới
executor.awaitTermination(60, TimeUnit.SECONDS); // Chờ tối đa 60 giây

// Cách 2: Tắt cưỡng bức
executor.shutdownNow(); // Interrupt các tác vụ đang chạy
```

## Middle Level

### Vòng đời ExecutorService

```
┌──────────┐    shutdown()    ┌───────────┐  mọi tác vụ ┌─────────┐
│ RUNNING  │ ──────────────→ │ SHUTDOWN  │ ────────────→ │ TIDYING │
│          │                 │           │               │         │
│ nhận     │  shutdownNow()  │ không     │               │         │
│ tác vụ   │ ──────────────→ │ nhận      │               │         │
│          │                 │ tác vụ    │               │         │
│ xử lý    │  ←───────────── │ hoàn tất  │               │         │
│          │   bị interrupt   │ hàng đợi  │               │         │
└──────────┘                 └───────────┘               └────┬────┘
      │                                                       │
      │                                                       │ terminated()
      │                                                       ▼
      │                                                 ┌───────────┐
      └────────────────────────────────────────────────│ TERMINATED│
                                                       └───────────┘
```

| Trạng thái     | Mô tả                                       |
| -------------- | ------------------------------------------- |
| **RUNNING**    | Nhận và xử lý các tác vụ                    |
| **SHUTDOWN**   | Không nhận cái mới, hoàn tất hàng đợi        |
| **STOP**       | Không nhận, interrupt các tác vụ đang chạy   |
| **TIDYING**    | Mọi tác vụ hoàn tất, các thread đã dừng      |
| **TERMINATED** | terminated() đã được thực thi               |

### submit(): Future và xử lý lỗi

```java
// Callable — trả về một kết quả
Future<String> future = executor.submit(() -> {
    return "Result";
});

// Lấy kết quả (chặn!)
String result = future.get();

// Lấy với timeout
try {
    String result = future.get(5, TimeUnit.SECONDS);
} catch (TimeoutException e) {
    future.cancel(true); // Hủy tác vụ
}
// cancel(true) gửi interrupt() tới tác vụ.
// Tác vụ phải tự kiểm tra Thread.interrupted() và kết thúc.
// Nếu tác vụ không xử lý interrupt — nó sẽ tiếp tục chạy!
```

### invokeAll() và invokeAny()

```java
// invokeAll() — chờ TẤT CẢ các tác vụ
List<Callable<String>> tasks = List.of(
    () -> "Task 1",
    () -> "Task 2",
    () -> "Task 3"
);
List<Future<String>> futures = executor.invokeAll(tasks);
// Chặn cho tới khi tất cả hoàn thành

// invokeAny() — chờ tác vụ ĐẦU TIÊN thành công
String result = executor.invokeAny(tasks);
// Trả về kết quả của tác vụ hoàn thành đầu tiên, hủy phần còn lại
```

### Tắt Pool đúng cách

```java
public void shutdownGracefully(ExecutorService executor) {
    executor.shutdown(); // 1. Ngừng nhận
    try {
        if (!executor.awaitTermination(60, TimeUnit.SECONDS)) { // 2. Chờ
            executor.shutdownNow(); // 3. Ép buộc
            if (!executor.awaitTermination(30, TimeUnit.SECONDS)) {
                System.err.println("Pool did not terminate");
            }
        }
    } catch (InterruptedException e) {
        executor.shutdownNow();
        Thread.currentThread().interrupt(); // Khôi phục cờ interrupt
    }
}
```

### submit() vs execute() — Cái bẫy Exception

```java
// execute() — exception được ném ngay lập tức
executor.execute(() -> {
    throw new RuntimeException("Error!"); // → UncaughtExceptionHandler
});

// submit() — exception bị "ẩn" trong Future
Future<?> future = executor.submit(() -> {
    throw new RuntimeException("Error!");
});
// Không có lỗi cho tới khi bạn gọi future.get()!
try {
    future.get(); // → ExecutionException
} catch (ExecutionException e) {
    System.out.println(e.getCause()); // → RuntimeException: Error!
}
```

## Senior Level

> Chi tiết hiện thực của ThreadPoolExecutor (ctl, các hàng đợi, ThreadFactory) — trong file [[12. What is a Thread Pool]].

### Rò rỉ Thread Pool

```java
// XẤU: tạo pool bên trong một method
public void process() {
    ExecutorService executor = Executors.newFixedThreadPool(10);
    executor.submit(() -> doWork());
    executor.shutdown();
    // Nếu doWork() ném một exception — shutdown() không được gọi
    // Các thread bị rò rỉ!
}

// TỐT: pool là một singleton hoặc được quản lý bởi một container
@Component
public class TaskProcessor {
    private final ExecutorService executor;

    public TaskProcessor() {
        this.executor = new ThreadPoolExecutor(...);
    }

    @PreDestroy
    public void shutdown() {
        shutdownGracefully(executor);
    }
}
```

### Correlation ID / Trace Context

```java
// Vấn đề: Trace ID không được truyền đi tự động
executor.submit(() -> {
    // MDC.get("traceId") = null!
});

// Giải pháp: wrapper
public class TracingExecutorService implements ExecutorService {
    private final ExecutorService delegate;

    public Future<?> submit(Runnable task) {
        Map<String, String> mdcContext = MDC.getCopyOfContextMap();
        return delegate.submit(() -> {
            if (mdcContext != null) MDC.setContextMap(mdcContext);
            try {
                task.run();
            } finally {
                MDC.clear();
            }
        });
    }
}
```

### Chẩn đoán

#### Metric để giám sát

```java
// Xuất ra Prometheus:
executor.getActiveCount();         // Các thread đang hoạt động
executor.getQueue().size();        // Kích thước hàng đợi
executor.getCompletedTaskCount();  // Các tác vụ đã hoàn thành
executor.getTaskCount();           // Tổng số tác vụ
executor.getPoolSize();            // Kích thước pool
```

#### Future.isDone() / isCancelled()

```java
Future<?> future = executor.submit(task);

// Không chặn
if (future.isDone()) {
    System.out.println("Completed");
}
if (future.isCancelled()) {
    System.out.println("Cancelled");
}
```

### Best Practices

1. **Đừng tạo ExecutorService bên trong một method** — rò rỉ thread
2. **Dùng submit()** — nếu bạn cần xử lý lỗi
3. **Luôn gọi shutdown()** — trong finally hoặc @PreDestroy
4. **ArrayBlockingQueue** — bảo vệ khỏi OOM
5. **CallerRunsPolicy** — back-pressure khi quá tải
6. **Custom ThreadFactory** — đặt tên thread
7. **Truyền Trace ID** — cho microservices
8. **Giám sát queue.size()** — hàng đợi tăng dần = suy giảm

## Tóm tắt phỏng vấn (Interview Cheat Sheet)

**Cần phải biết:**
- ExecutorService — interface để quản lý các thread pool: submit tác vụ, lấy kết quả, graceful shutdown
- execute(Runnable) = void, exception in ra console; submit() = Future, exception bị ẩn trong ExecutionException
- submit(Callable<T>) trả về Future<T> — có thể lấy kết quả và xử lý lỗi qua get()
- Vòng đời: RUNNING → SHUTDOWN (shutdown()) → STOP (shutdownNow()) → TIDYING → TERMINATED
- invokeAll() — chờ TẤT CẢ các tác vụ; invokeAny() — trả về kết quả của cái ĐẦU TIÊN thành công, hủy phần còn lại
- Graceful shutdown: shutdown() → awaitTermination(timeout) → shutdownNow() → awaitTermination
- Future.get(timeout) ném TimeoutException — khi timeout, gọi future.cancel(true)
- ExecutorService nên được quản lý bởi một container (Spring @Bean) hoặc singleton, KHÔNG tạo bên trong một method

**Các câu hỏi phụ thường gặp:**
- **Khác biệt giữa execute() vs submit() là gì?** — execute là "fire and forget", submit cho phép theo dõi kết quả và lỗi qua Future
- **Tại sao submit() không ném exception ngay lập tức?** — Exception được bọc trong ExecutionException và chỉ có sẵn qua future.get().getCause()
- **shutdown() khác shutdownNow() như thế nào?** — shutdown hoàn tất hàng đợi, shutdownNow interrupt các tác vụ đang chạy qua interrupt()
- **Làm sao truyền MDC/Trace ID trong ExecutorService?** — Wrapper: MDC.getCopyOfContextMap() trước submit, MDC.setContextMap() bên trong tác vụ

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- "Tôi tạo ExecutorService bên trong một method" — rò rỉ thread nếu shutdown() không được gọi
- "submit() sẽ hiển thị exception ngay lập tức" — không, bạn cần gọi future.get()
- "shutdownNow() đảm bảo dừng mọi tác vụ" — không, nó chỉ gửi interrupt(), các tác vụ phải tự xử lý
- "cancel(true) tức thì giết tác vụ" — không, nó chỉ đặt cờ interrupted, tác vụ phải kiểm tra nó
