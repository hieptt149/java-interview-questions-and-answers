# What Is Compact Constructor in Record? (Compact constructor trong Record là gì)

## 🟢 Junior Level

**Compact constructor** là một dạng constructor đặc biệt trong Record được dùng **chỉ để validation và chuẩn hóa** dữ liệu.

Nó không chứa chữ ký — trình biên dịch tự hiểu đây là compact constructor.

```java
public record User(String name, int age) {
    // Compact constructor — chỉ có body, không có chữ ký
    public User {
        if (age < 0) {
            throw new IllegalArgumentException("Age cannot be negative");
        }
    }
}
```

**Khác biệt so với constructor thông thường:**
```java
// Constructor thông thường
public User(String name, int age) {
    this.name = name;
    this.age = age;
}

// Compact constructor (chỉ validation)
public User {
    if (age < 0) {
        throw new IllegalArgumentException();
    }
}
```

## 🟡 Middle Level

### Cách Hoạt Động

Compact constructor được **inline vào canonical constructor** tự động:

```java
public record Email(String value) {
    public Email {
        // Code này sẽ thực thi TRƯỚC khi gán trường
        if (value == null || !value.contains("@")) {
            throw new IllegalArgumentException("Invalid email");
        }
    }
}

// Trình biên dịch sinh ra:
public Email(String value) {
    // Code từ compact constructor
    if (value == null || !value.contains("@")) {
        throw new IllegalArgumentException("Invalid email");
    }
    // Sau đó gán
    this.value = value;
}
```

**Quan trọng:** Các tham số trong compact constructor **không phải final** — bạn có thể thay đổi giá trị trước khi gán!

```java
public record Email(String value) {
    public Email {
        value = value.toLowerCase().trim();  // ✅ chuẩn hóa
    }
}
```

### Các Lỗi Thường Gặp

1. **Cố gắng gán `this.value`:**
```java
public record User(String name) {
    public User {
        // ❌ Không thể dùng this.value
        this.name = name.toUpperCase();  // lỗi biên dịch

        // ✅ Dùng tên thuần túy
        name = name.toUpperCase();  // OK — đây là tham số, không phải trường
    }
}
```

2. **Cố gắng thêm trường:**
```java
public record User() {
    public User {
        // ❌ Không thể thêm một trường
        int extra = 0;  // lỗi biên dịch
    }
}
```

### Ứng Dụng Thực Tế

**1. Validation:**
```java
public record Money(BigDecimal amount) {
    public Money {
        Objects.requireNonNull(amount, "Amount cannot be null");
        if (amount.compareTo(BigDecimal.ZERO) < 0) {
            throw new IllegalArgumentException("Negative amount");
        }
    }
}
```

**2. Chuẩn hóa:**
```java
public record PhoneNumber(String value) {
    public PhoneNumber {
        // Loại bỏ mọi thứ trừ chữ số
        value = value.replaceAll("[^0-9+]", "");
    }
}
```

**3. Chuẩn hóa với object mutable:**
```java
public record TagCloud(List<String> tags) {
    public TagCloud {
        // Bản sao phòng thủ
        tags = new ArrayList<>(tags);
        // Chuẩn hóa
        tags.replaceAll(String::toLowerCase);
        tags.sort(null);
    }
}
```

## 🔴 Senior Level

### Triển Khai Nội Bộ

**Desugaring:**
```java
// Source code
public record User(String name, int age) {
    public User {
        if (age < 0) throw new IllegalArgumentException();
        name = name.toUpperCase();
    }
}

// Code sau desugar
public final class User extends Record {
    private final String name;
    private final int age;

    public User(String name, int age) {
        // Code từ compact constructor
        if (age < 0) throw new IllegalArgumentException();
        name = name.toUpperCase();

        // Gán trường (trình biên dịch sinh ra)
        this.name = name;
        this.age = age;
    }
}
```

**Ràng buộc:**
- Tham số của compact constructor **effectively final**, nhưng không phải final
- Bạn có thể sửa đổi tham số trước khi gán
- Không thể truy cập `this` trước khi gán
// Vì chữ ký của canonical constructor không chứa throws,
// checked exception phải được bọc trong unchecked.
- Không thể ném checked exception (vì canonical constructor không khai báo throws)

### Đánh Đổi Kiến Trúc

**Compact constructor so với constructor đầy đủ:**

| Khía cạnh                      | Compact   | Đầy đủ      |
| --------------------------- | ------------ | ----------- |
| **Validation**               | ✅ Lý tưởng    | ✅ Hoạt động  |
| **Chuẩn hóa**            | ✅ Hoạt động   | ✅ Hoạt động  |
| **Sửa đổi tham số**    | ✅ Cho phép  | ✅ Cho phép     |
| **Ủy quyền**           | ❌ Không thể     | ✅ Có thể     |
| **Nhiều constructor** | ❌ Một       | ✅ Nhiều |

### Edge Cases

**1. Chuẩn hóa các object mutable:**
```java
public record DateRange(LocalDate start, LocalDate end) {
    public DateRange {
        Objects.requireNonNull(start);
        Objects.requireNonNull(end);
        if (start.isAfter(end)) {
            // Tự động sửa
            var temp = start;
            start = end;
            end = temp;
        }
    }
}
```

**2. Compact constructor với checked exception:**
```java
public record JsonData(String json) {
    public JsonData {
        try {
            Json.parse(json);
        } catch (JsonParseException e) {
            // ❌ Không thể ném checked exception
            // ✅ Bọc trong unchecked
            throw new IllegalArgumentException("Invalid JSON", e);
        }
    }
}
```

**3. Compact constructor + constructor bổ sung:**
```java
public record Point(int x, int y) {
    // Compact — cho validation
    public Point {
        if (x < 0 || y < 0) {
            throw new IllegalArgumentException("Negative coordinates");
        }
    }

    // Bổ sung — cho tiện lợi
    public Point(int value) {
        this(value, value);  // gọi canonical (có validation)
    }
}
```

### Hiệu Năng

```
Compact constructor:
- Overhead bằng không — code được inline vào canonical constructor
- JIT có thể tối ưu hóa validation
- Không có lời gọi bổ sung
```

### Kinh Nghiệm Production

**Value object với các bất biến:**
```java
public record Range(int min, int max) {
    public Range {
        if (min > max) {
            throw new IllegalArgumentException(
                "Min (%d) cannot be greater than max (%d)".formatted(min, max));
        }
    }

    public boolean contains(int value) {
        return value >= min && value <= max;
    }
}

// Sử dụng
Range r = new Range(1, 10);  // OK
Range bad = new Range(10, 1);  // ném ra IllegalArgumentException
```

**DDD Value Object:**
```java
public record UserId(UUID value) {
    public UserId {
        Objects.requireNonNull(value, "UserId cannot be null");
    }

    public static UserId generate() {
        return new UserId(UUID.randomUUID());
    }

    public static UserId of(String value) {
        return new UserId(UUID.fromString(value));
    }
}

public record Email(String value) {
    private static final Pattern EMAIL_PATTERN =
        Pattern.compile("^[A-Za-z0-9+_.-]+@[A-Za-z0-9.-]+$");

    public Email {
        Objects.requireNonNull(value, "Email cannot be null");
        value = value.toLowerCase().trim();
        if (!EMAIL_PATTERN.matcher(value).matches()) {
            throw new IllegalArgumentException("Invalid email format");
        }
    }
}
```

### Best Practices

```java
// ✅ Dùng compact constructor cho validation
public record Age(int value) {
    public Age {
        if (value < 0 || value > 150) {
            throw new IllegalArgumentException("Invalid age");
        }
    }
}

// ✅ Cho chuẩn hóa các object mutable
public record Tags(Set<String> tags) {
    public Tags {
        tags = Set.copyOf(tags);  // bản sao bất biến
    }
}
```

## 🎯 Interview Cheat Sheet

**Cần phải biết:**
- Compact constructor — dạng không có chữ ký, chỉ dùng cho validation và chuẩn hóa
- Code của compact constructor được inline vào canonical TRƯỚC khi gán trường
- Có thể sửa đổi tham số: `value = value.toLowerCase().trim()` — điều này thay đổi giá trị trước khi gán
- Không thể dùng `this.field = ...` — chỉ dùng tên tham số
- Không thể ném checked exception trực tiếp (canonical constructor không khai báo throws)
- Không thể thêm trường trong compact constructor

**Các câu hỏi phụ thường gặp:**
- **Tại sao cần compact constructor?** — Để validation và chuẩn hóa mà không cần boilerplate
- **Có thể thay đổi giá trị tham số không?** — Có, đây là thực hành bình thường: `value = value.trim()`
- **Tại sao không thể dùng this.field?** — Việc gán trường được sinh tự động sau compact constructor
- **Có thể ném checked exception không?** — Không, phải bọc trong unchecked (IllegalArgumentException)

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- ❌ "Compact constructor gán trường" — Việc gán là tự động, chỉ tham số mới có thể thay đổi
- ❌ "Compact constructor có chữ ký" — Không có chữ ký, trình biên dịch xác định bằng dạng
- ❌ "Bạn có thể tạo một trường bổ sung" — Trường instance bị cấm trong Record
- ❌ "Bạn có thể ném IOException từ compact constructor" — Chỉ ngoại lệ unchecked
