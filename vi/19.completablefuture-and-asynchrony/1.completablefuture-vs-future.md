# What is CompletableFuture and How Does It Differ from Future? (CompletableFuture là gì và khác gì so với Future)

## 🟢 Junior Level

**CompletableFuture** là một class trong Java (được giới thiệu ở Java 8) đại diện cho **kết quả của một thao tác bất đồng bộ** chưa sẵn sàng nhưng sẽ có trong tương lai.

Sự khác biệt chính so với `Future` thông thường:
- `Future` — chỉ **chờ đợi** kết quả (`get()` chặn thread)
- `CompletableFuture` — bạn có thể **xây dựng chuỗi** các hành động, kết hợp chúng, xử lý lỗi

```java
// Future — cần chờ và chặn thread
Future<String> future = executor.submit(() -> "Hello");
String result = future.get();  // chặn thread!

// CompletableFuture — có thể xây dựng chuỗi
CompletableFuture<String> cf = CompletableFuture.supplyAsync(() -> "Hello");
cf.thenApply(s -> s + " World")
  .thenAccept(System.out::println);  // không chặn!
```

**Analogy đơn giản:**
- `Future` — giống như một hóa đơn tại nhà hàng: bạn chờ đồ ăn sẵn sàng
- `CompletableFuture` — giống như giao hàng: bạn đặt hàng, và họ sẽ mang đến cho bạn trong khi bạn làm việc riêng của mình

## 🟡 Middle Level

### Cách Hoạt Động

**Hạn chế của Future:**
```java
// ❌ Future — không thể xây dựng chuỗi
Future<Integer> future = executor.submit(() -> 42);

// Cần chặn và xử lý thủ công
try {
    Integer result = future.get();  // chặn
    Integer doubled = result * 2;
} catch (InterruptedException | ExecutionException e) {
    // xử lý thủ công
}
```

**Khả năng của CompletableFuture:**
```java
// ✅ Chuỗi các hành động
CompletableFuture<Integer> cf = CompletableFuture.supplyAsync(() -> 42);

cf.thenApply(result -> result * 2)       // biến đổi
  .thenAccept(doubled -> System.out.println(doubled))  // tiêu thụ
  .exceptionally(ex -> {                 // xử lý lỗi
      System.err.println("Error: " + ex);
      return null;
  });

// Không chặn thread chính!
```

**Tạo:**
```java
// supplyAsync — có giá trị trả về
CompletableFuture<String> cf1 =
    CompletableFuture.supplyAsync(() -> "Hello");

// runAsync — không có giá trị trả về
CompletableFuture<Void> cf2 =
    CompletableFuture.runAsync(() -> System.out.println("Done"));
```

### Các Lỗi Thường Gặp

1. **Quên Async — thực thi trong cùng thread:**
```java
CompletableFuture.supplyAsync(() -> "Hello")
    .thenApply(s -> {
        // Thực thi trong ForkJoinPool.commonPool()
        return s + " World";
    });
// Đây KHÔNG phải là lỗi, đó là một lựa chọn có chủ ý. thenApply trong cùng thread —
// lựa chọn đúng cho các biến đổi CPU nhẹ. Vấn đề chỉ nảy sinh nếu
// thenApply thực hiện một thao tác chặn.

// so với
CompletableFuture<String> cf = CompletableFuture.completedFuture("Hello");
cf.thenApply(s -> s + " World");  // thực thi trong thread gọi!
```

2. **Ngoại lệ không được xử lý:**
```java
// ❌ Ngoại lệ bị mất
CompletableFuture.supplyAsync(() -> {
    throw new RuntimeException("Error");
}).thenApply(s -> s.toUpperCase());

// ✅ Xử lý
CompletableFuture.supplyAsync(() -> {
    throw new RuntimeException("Error");
}).exceptionally(ex -> "default");
```

## 🔴 Senior Level

### Triển Khai Nội Bộ

**CompletableFuture vs Future:**
```java
// Future — interface
public interface Future<V> {
    boolean cancel(boolean mayInterruptIfRunning);
    boolean isCancelled();
    boolean isDone();
    V get() throws InterruptedException, ExecutionException;
    V get(long timeout, TimeUnit unit) throws ...;
}

// CompletableFuture — triển khai + CompletionStage
public class CompletableFuture<T> implements Future<T>, CompletionStage<T> {
    // CompletionStage cung cấp 40+ phương thức để kết hợp (composition)
}
```

**Cấu trúc nội bộ:**
```java
// CompletableFuture dùng các thuật toán lock-free
// CAS (Compare-And-Swap) cho việc hoàn thành
// Stack của completion/dependency cho các chuỗi

class CompletableFuture<T> {
    volatile Object result;  // hoặc value hoặc AltResult (ngoại lệ)
    // AltResult — class wrapper nội bộ của JDK cho ngoại lệ.
    // Cho phép lưu null như một kết quả hợp lệ và phân biệt nó với một ngoại lệ.
    volatile Completion stack;  // stack dependency

    // CAS cho việc hoàn thành
    boolean completeValue(T t) {
        // compareAndSwap để thiết lập result
    }
}
```

### Đánh Đổi Kiến Trúc

| Future                | CompletableFuture              |
| --------------------- | ------------------------------ |
| get() chặn        | Không chặn                   |
| Không có xử lý lỗi     | Xử lý lỗi đầy đủ            |
| Không thể kết hợp        | thenCombine, allOf, anyOf      |
| Cần ExecutorService | Có ForkJoinPool riêng theo mặc định    |

### Edge Cases

**1. Executor Mặc Định:**
```java
// CompletableFuture dùng ForkJoinPool.commonPool()
// Đối với thao tác I/O — xấu (quá ít thread)
CompletableFuture.supplyAsync(() -> {
    // Thao tác I/O — cần nhiều thread hơn!
    return httpClient.get(url);
});

// ✅ Executor tùy chỉnh
ExecutorService ioExecutor = Executors.newFixedThreadPool(20);
CompletableFuture.supplyAsync(() -> httpClient.get(url), ioExecutor);
```

**2. Lan truyền ngoại lệ:**
```java
// Ngoại lệ được bọc trong CompletionException
CompletableFuture.supplyAsync(() -> {
    throw new RuntimeException("Original");
}).thenApply(s -> s.toUpperCase())
  .exceptionally(ex -> {
      // ex — CompletionException với nguyên nhân gốc
      Throwable cause = ex.getCause();  // "Original"
      return null;
  });
```

### Hiệu Năng

```
Thao tác             | Future | CompletableFuture
----------------------|--------|------------------
Tạo              | 5 ns   | 10 ns
get() (chặn)      | 100μs+ | 100μs+
thenApply (chuỗi)     | N/A    | 5-10 ns
Xử lý lỗi        | Thủ công | Tích hợp sẵn

ForkJoinPool.commonPool():
- Kích thước = availableProcessors - 1
- Đối với tác vụ CPU-bound — OK
- Đối với I/O — cần Executor riêng
```

### Kinh Nghiệm Production

**Lời gọi API bất đồng bộ:**
```java
@Service
public class UserService {
    private final RestTemplate restTemplate;
    private final ExecutorService executor;

    public CompletableFuture<User> getUserAsync(Long userId) {
        return CompletableFuture.supplyAsync(() -> {
            return restTemplate.getForObject(
                "http://api/users/" + userId, User.class
            );
        }, executor);
    }

    // Kết hợp nhiều lời gọi
    public CompletableFuture<UserProfile> getProfile(Long userId) {
        CompletableFuture<User> user = getUserAsync(userId);
        CompletableFuture<Order> lastOrder = getLastOrderAsync(userId);

        return user.thenCombine(lastOrder, (u, o) ->
            new UserProfile(u, o)
        );
    }
}
```

### Best Practices

```java
// ✅ Luôn xử lý ngoại lệ
cf.exceptionally(ex -> defaultValue);

// ✅ Dùng Executor riêng cho I/O
CompletableFuture.supplyAsync(task, ioExecutor);

// ✅ Đừng chặn nếu không cần thiết
// ❌ cf.get() — chỉ khi thực sự cần

// ❌ Đừng bỏ qua CompletableFuture
// ❌ Đừng dùng commonPool cho I/O
```

## 🎯 Interview Cheat Sheet

**Cần phải biết:**
- CompletableFuture xuất hiện ở Java 8, triển khai Future + CompletionStage
- CompletionStage cung cấp 40+ phương thức để kết hợp
- ForkJoinPool.commonPool() được dùng theo mặc định (availableProcessors - 1)
- supplyAsync() — có giá trị trả về, runAsync() — không có
- Ngoại lệ được bọc trong CompletionException
- thenApply/thenAccept/thenRun — để tạo chuỗi, thenCombine/allOf/anyOf — để kết hợp

**Các câu hỏi phụ thường gặp:**
- **Nó khác gì so với Future?** — Future chỉ có get() chặn, CompletableFuture — không chặn với chuỗi và xử lý lỗi
- **Pool nào được dùng theo mặc định?** — ForkJoinPool.commonPool(), đối với I/O cần Executor riêng
- **Cách xử lý lỗi?** — exceptionally(), handle(), whenComplete()
- **Có thể hoàn thành thủ công không?** — Có, complete() hoặc completeExceptionally()

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- "CompletableFuture chặn thread" — nó không chặn theo thiết kế
- "Tôi dùng commonPool cho HTTP request" — thread pool starvation (đói tài nguyên thread pool)
- "Tôi bỏ qua CompletableFuture mà không xử lý" — ngoại lệ bị mất
