# Can You Create an Array of Generic Type? (Có thể tạo một mảng của kiểu generic không)

## 🟢 Junior Level

**Không, bạn không thể tạo trực tiếp.** Java không cho phép tạo mảng của kiểu generic do type erasure.

```java
// ❌ Không thể làm điều này
public class Box<T> {
    private T[] array = new T[10];  // lỗi biên dịch: "generic array creation"
}
```

**Tại sao:** Mảng trong Java **biết kiểu của chúng tại runtime**, trong khi generics **mất kiểu** sau khi biên dịch (type erasure). Hai cơ chế này không tương thích với nhau.

**Giải pháp:**
```java
// Giải pháp 1: Mảng Object với cast
public class Box<T> {
    private T[] array = (T[]) new Object[10];  // cảnh báo unchecked
}

// Giải pháp 2: ArrayList thay vì mảng
public class Box<T> {
    private List<T> list = new ArrayList<>();
}

// Giải pháp 3: Truyền Class<T>
public class Box<T> {
    private T[] array;

    public Box(Class<T> type, int size) {
        array = (T[]) Array.newInstance(type, size);
    }
}
```

## 🟡 Middle Level

### Tại Sao Không Được Phép?

**Các mô hình xung đột:**
- **Mảng** — reified (biết kiểu của chúng tại runtime)
- **Generics** — type erasure (kiểu bị mất)

```java
// Nếu điều này được phép:
List<String>[] stringLists = new List<String>[10];
Object[] objects = stringLists;  // mảng là covariant
objects[0] = List.of(42);        // List<Integer> — trình biên dịch không phàn nàn!
String s = stringLists[0].get(0); // ClassCastException!
```

Điều này phá vỡ **tính an toàn kiểu** — lỗi không được bắt tại compile time.

### Các Giải Pháp Hoạt Động

**1. Unchecked cast:**
```java
public class GenericStack<T> {
    private T[] elements;
    private int size = 0;

    @SuppressWarnings("unchecked")
    public GenericStack(int capacity) {
        elements = (T[]) new Object[capacity];  // cảnh báo unchecked
    }

    public void push(T item) {
        elements[size++] = item;
    }

    public T pop() {
        return elements[--size];
    }
}
```

**2. Reflection:**
```java
public class GenericArray<T> {
    private final T[] array;

    public GenericArray(Class<T> type, int size) {
        array = (T[]) Array.newInstance(type, size);
    }

    public void set(int index, T value) {
        array[index] = value;
    }

    public T get(int index) {
        return array[index];
    }
}

// Sử dụng
GenericArray<String> strings = new GenericArray<>(String.class, 10);
strings.set(0, "Hello");
```

**3. Collection thay vì mảng:**
```java
// Giải pháp tốt nhất trong hầu hết các trường hợp
public class Box<T> {
    private final List<T> items = new ArrayList<>();

    public void add(T item) { items.add(item); }
    public T get(int index) { return items.get(index); }
}
```

### Các Lỗi Thường Gặp

1. **Bỏ qua cảnh báo unchecked:**
```java
// ⚠️ Cảnh báo bị ẩn, nhưng vấn đề vẫn còn
T[] array = (T[]) new Object[10];

// Tốt hơn — ghi lại tài liệu tại sao điều này an toàn
```

2. **Heap pollution:**
```java
// Nguy hiểm — có thể đặt sai kiểu
Object[] raw = new Object[10];
String[] strings = (String[]) raw;  // ClassCastException!
```

## 🔴 Senior Level

### Triển Khai Nội Bộ

**Tại sao mảng là reified:**
```
Đặc tả JVM:
- Mảng lưu kiểu thành phần trong class file
- Kiểm tra runtime mỗi lần truy cập
- ArrayStoreException khi sai kiểu

// Ví dụ
String[] arr = new String[10];
arr[0] = "Hello";     // OK
arr[1] = 42;          // ArrayStoreException tại runtime!
```

**Xung đột type erasure:**
```
// Nếu mảng generic được cho phép:
List<String>[] lists = new List<String>[5];
Object[] obj = lists;  // covariant
obj[0] = new ArrayList<Integer>();  // OK đối với trình biên dịch
String s = lists[0].get(0);         // ClassCastException!

// Mảng không thể kiểm tra kiểu phần tử tại runtime,
// vì List<String> và List<Integer> là cùng một raw type sau erasure
```

### Đánh Đổi Kiến Trúc

**Các cách tiếp cận mảng generic:**

| Cách tiếp cận            | Ưu điểm      | Nhược điểm              |
| ------------------- | --------- | ----------------- |
| **Object[] + cast** | Đơn giản    | Cảnh báo unchecked |
| **Reflection**      | An toàn kiểu | Cần Class<T>    |
| **Collection**     | An toàn      | Overhead cao hơn     |

### Edge Cases

**1. Varargs generic:**
```java
// Varargs là mảng!
public static <T> List<T> asList(T... items) {
    return Arrays.asList(items);
}

// ⚠️ Cảnh báo heap pollution
asList("a", "b", "c");  // OK
// Nhưng trình biên dịch cảnh báo

// @SafeVarargs khắc phục
@SafeVarargs
public static <T> List<T> safeAsList(T... items) {
    return Arrays.asList(items);
}
```

**2. Mảng generic lồng nhau:**
```java
// Còn khó hơn — kiểu lồng nhau
public class Matrix<T> {
    // ❌ Không thể làm điều này
    private T[][] matrix = new T[10][10];  // lỗi

    // ✅ Qua Reflection
    private T[][] matrix;

    public Matrix(Class<T> type, int rows, int cols) {
        matrix = (T[][]) Array.newInstance(type, rows, cols);
    }
}
```

**3. Vấn đề ArrayList.toArray():**
```java
List<String> list = List.of("a", "b", "c");

// ❌ Không thể làm điều này
String[] array = (String[]) list.toArray();  // ClassCastException
// toArray() trả về Object[]

// ✅ Cách tiếp cận đúng
String[] array = list.toArray(new String[0]);
// Hoặc Java 11+
String[] array = list.toArray(String[]::new);
```

### Hiệu Năng

```
Mảng vs ArrayList:
Thao tác         | Mảng        | ArrayList
------------------|--------------|----------
Truy cập            | 1 ns         | 1 ns
Thêm               | N/A (cố định)  | 1-10 ns (resize)
Bộ nhớ            | Tối thiểu      | + overhead
Kiểm tra kiểu        | Runtime      | Thời gian biên dịch

Tạo mảng generic:
- Object[] + cast: Overhead bằng không
- Reflection: ~5-10 ns mỗi lần tạo
- Collection: +10-20% bộ nhớ
```

### Kinh Nghiệm Production

**Collection nội bộ của Java:**
```java
// ArrayList nội bộ — dùng Object[] + cast
public class ArrayList<E> {
    private transient Object[] elementData;  // KHÔNG PHẢI E[]

    @SuppressWarnings("unchecked")
    public E get(int index) {
        return (E) elementData[index];  // unchecked cast
    }
}

// HashMap — tương tự
transient Node<K,V>[] table;  // mảng của Node thô

// Điều này an toàn vì ArrayList kiểm soát nội bộ tất cả các lần ghi
// và không cho phép các phần tử sai kiểu.
```

**Mảng generic an toàn:**
```java
public class SafeGenericArray<T> {
    private final Object[] array;
    private final Class<T> type;

    public SafeGenericArray(Class<T> type, int size) {
        this.type = type;
        this.array = new Object[size];
    }

    public void set(int index, T value) {
        if (!type.isInstance(value)) {
            throw new IllegalArgumentException();
        }
        array[index] = value;
    }

    @SuppressWarnings("unchecked")
    public T get(int index) {
        return (T) array[index];
    }
}
```

### Best Practices

```java
// ✅ Dùng collection thay vì mảng
List<T> list = new ArrayList<>();

// ✅ Nếu bạn cần một mảng — Object[] + cast
@SuppressWarnings("unchecked")
private T[] array = (T[]) new Object[size];

// ✅ @SafeVarargs cho phương thức varargs
@SafeVarargs
public static <T> T[] merge(T[] a1, T[] a2) { }

// ✅ Reflection khi bạn cần một mảng an toàn kiểu
T[] array = (T[]) Array.newInstance(type, size);

// ❌ new T[]
// ❌ Bỏ qua cảnh báo unchecked mà không có lý do
// ❌ Heap pollution — để lộ mảng generic ra bên ngoài
```

## 🎯 Interview Cheat Sheet

**Cần phải biết:**
- `new T[]` — lỗi biên dịch: "generic array creation"
- Lý do: mảng là reified (biết kiểu tại runtime), generics — type erasure (kiểu bị mất)
- Giải pháp 1: `Object[]` + unchecked cast `(T[]) new Object[size]`
- Giải pháp 2: Reflection — `Array.newInstance(type, size)` với `Class<T>` được truyền vào
- Giải pháp 3: Dùng `ArrayList<T>` thay vì mảng
- @SafeVarargs ẩn cảnh báo cho phương thức varargs
- ArrayList nội bộ dùng `Object[]` + unchecked cast

**Các câu hỏi phụ thường gặp:**
- **Tại sao không thể tạo một mảng generic?** — Xung đột giữa mảng reified và generics bị type-erased
- **ArrayList lưu trữ phần tử như thế nào?** — Object[] elementData + unchecked cast khi get()
- **Heap pollution là gì?** — Khi một collection generic chứa các phần tử sai kiểu
- **Unchecked cast trong ArrayList có an toàn không?** — Có, ArrayList kiểm soát nội bộ tất cả các lần ghi

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- ❌ "Mảng generic có thể được tạo qua unchecked cast mà không có vấn đề gì" — Heap pollution có thể xảy ra
- ❌ "Mảng generic hoạt động trong Java" — Bị cấm ở tầng trình biên dịch
- ❌ "ArrayList dùng T[] nội bộ" — ArrayList dùng Object[], không phải T[]
- ❌ "Heap pollution là lỗi JVM" — Đó là cảnh báo compile-time, một vấn đề an toàn kiểu
