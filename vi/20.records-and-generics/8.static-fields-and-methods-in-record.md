# Can You Declare Static Fields and Methods in Record? (Có thể khai báo trường và phương thức static trong Record không)

## 🟢 Junior Level

**Có, bạn có thể!** Record hỗ trợ trường và phương thức `static`. Đây là cách duy nhất để thêm điều gì đó vào Record ngoài các thành phần canonical.

```java
public record User(String name, int age) {
    // ✅ Trường static
    public static final int MAX_AGE = 150;

    // ✅ Phương thức static
    public static User anonymous() {
        return new User("Anonymous", 0);
    }
}

// Sử dụng
User.MAX_AGE;  // 150
User.anonymous();  // User[name=Anonymous, age=0]
```

**Bạn không thể:**
- ❌ Trường instance (không static)
- ✅ Chỉ trường static

## 🟡 Middle Level

### Cách Hoạt Động

**Trường và phương thức static:**
```java
public record Color(int r, int g, int b) {
    // ✅ Hằng số static
    public static final Color RED = new Color(255, 0, 0);
    public static final Color GREEN = new Color(0, 255, 0);
    public static final Color BLUE = new Color(0, 0, 255);

    // ✅ Phương thức factory static
    public static Color fromHex(String hex) {
        int r = Integer.parseInt(hex.substring(1, 3), 16);
        int g = Integer.parseInt(hex.substring(3, 5), 16);
        int b = Integer.parseInt(hex.substring(5, 7), 16);
        return new Color(r, g, b);
    }

    // ✅ Bộ đếm static
    private static final AtomicLong COUNTER = new AtomicLong(0);

    public Color {
        COUNTER.incrementAndGet();
    }

    public static long count() {
        return COUNTER.get();
    }
}
```

### Các Lỗi Thường Gặp

1. **Cố gắng thêm trường instance:**
```java
public record User(String name) {
    // ❌ Trường instance — lỗi biên dịch
    private int mutableField = 0;

    // ✅ Chỉ static
    private static int counter = 0;
}
```

2. **Trường static mutable:**
```java
public record Config() {
    // ⚠️ Nguy hiểm — trạng thái static mutable
    public static Map<String, String> settings = new HashMap<>();

    // ✅ Tốt hơn — bất biến
    public static final Map<String, String> DEFAULTS = Map.of(
        "locale", "en",
        "timezone", "UTC"
    );
}
```

### Ứng Dụng Thực Tế

**1. Hằng số:**
```java
public record Money(BigDecimal amount, Currency currency) {
    public static final Money ZERO_USD = new Money(BigDecimal.ZERO, Currency.USD);
    public static final Money ZERO_EUR = new Money(BigDecimal.ZERO, Currency.EUR);
}
```

**2. Phương thức factory:**
```java
public record Range(int min, int max) {
    public static Range fromString(String str) {
        String[] parts = str.split("-");
        return new Range(Integer.parseInt(parts[0]), Integer.parseInt(parts[1]));
    }

    public static Range of(int value) {
        return new Range(value, value);
    }
}
```

## 🔴 Senior Level

### Triển Khai Nội Bộ

**Trường static trong Record:**
```
// Trường static được lưu trong class, không phải trong instance
// Không ảnh hưởng đến:
// - Kích thước instance
// - equals() và hashCode() (không được xét trong static)
// - toString() (không bao gồm static)
// - Serialization
```

**Ràng buộc:**
- Trường static không phải là một phần của canonical constructor
- Phương thức static không thể truy cập trường instance
- Khởi tạo static xảy ra khi tải class

### Đánh Đổi Kiến Trúc

**Trường static so với tiện ích riêng biệt:**

| Cách tiếp cận              | Ưu điểm                  | Nhược điểm                    |
| ------------------- | ---------------------- | ------------------------- |
| **Static trong Record** | Logic gần dữ liệu | Record trở nên "béo" hơn |
| **Class riêng biệt** | Tách biệt sạch sẽ      | Nhiều file hơn             |

### Edge Cases

**1. Khởi tạo static với dependency:**
```java
public record Currency(String code, String symbol) {
    public static final Map<String, Currency> REGISTRY;

    static {
        REGISTRY = Map.of(
            "USD", new Currency("USD", "$"),
            "EUR", new Currency("EUR", "€"),
            "GBP", new Currency("GBP", "£")
        );
    }

    public static Currency of(String code) {
        return REGISTRY.get(code.toUpperCase());
    }
}
```

**2. Trạng thái static thread-safe:**
```java
public record IdGenerator(String prefix) {
    private static final AtomicLong SEQUENCE = new AtomicLong(0);

    public static String generate(IdGenerator gen) {
        return gen.prefix + "-" + SEQUENCE.incrementAndGet();
    }
}
```

### Hiệu Năng

```
Trường static:
- Overhead bằng không mỗi instance
- Khởi tạo khi tải class
- Khởi tạo thread-safe (JLS 12.4)
```

### Kinh Nghiệm Production

**Hằng số và factory:**
```java
public record HttpStatus(int code, String reason) {
    public static final HttpStatus OK = new HttpStatus(200, "OK");
    public static final HttpStatus CREATED = new HttpStatus(201, "Created");
    public static final HttpStatus NOT_FOUND = new HttpStatus(404, "Not Found");
    public static final HttpStatus SERVER_ERROR = new HttpStatus(500, "Server Error");

    public static HttpStatus fromCode(int code) {
        return switch (code) {
            case 200 -> OK;
            case 201 -> CREATED;
            case 404 -> NOT_FOUND;
            case 500 -> SERVER_ERROR;
            default -> new HttpStatus(code, "Unknown");
        };
    }
}
```

### Best Practices

```java
// ✅ Hằng số static
public record Role(String name) {
    public static final Role ADMIN = new Role("ADMIN");
    public static final Role USER = new Role("USER");
    public static final Role GUEST = new Role("GUEST");

    public static Pagination first() {
        return new Pagination(1, 20);
    }

// ❌ Trạng thái static mutable
// ❌ Trường static thay đổi sau khi khởi tạo
```

## 🎯 Interview Cheat Sheet

**Cần phải biết:**
- Record hỗ trợ trường static và phương thức static — đây là cách duy nhất để thêm điều gì đó ngoài các thành phần canonical
- Trường static không tham gia vào equals(), hashCode(), toString(), canonical constructor
- Hằng số static: `public static final Money ZERO_USD = ...`
- Phương thức factory static: `public static User anonymous() { ... }`
- Bộ đếm static qua AtomicLong để theo dõi việc tạo instance
- Trạng thái static mutable — anti-pattern (vấn đề thread safety)

**Các câu hỏi phụ thường gặp:**
- **Có thể thêm trường instance vào Record không?** — Không, chỉ trường static được cho phép
- **Trường static có ảnh hưởng đến equals/hashCode không?** — Không, chỉ các thành phần canonical được xét
- **Có thể tạo Record với pattern Registry không?** — Có, Map static để lưu instance
- **Có thể thêm khối khởi tạo static không?** — Có, khối static { } hoạt động như bình thường

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- ❌ "Trường static tham gia vào hashCode" — hashCode chỉ từ các thành phần canonical
- ❌ "Trường instance có thể thêm như private" — Bất kỳ trường instance nào — lỗi biên dịch
- ❌ "Trạng thái static mutable là ý tưởng tốt" — Thread safety và tính dự đoán bị ảnh hưởng
- ❌ "Phương thức static có thể truy cập trường instance" — Ngữ cảnh static không có quyền truy cập instance
