# Can You Add Additional Methods to a Record? (Có thể thêm phương thức bổ sung vào Record không)

## 🟢 Junior Level

**Có, bạn có thể!** Một Record không chỉ là một tập hợp các trường. Bạn có thể thêm bất kỳ phương thức nào, nhưng với một số ràng buộc.

**Những gì bạn có thể làm:**
```java
public record Money(BigDecimal amount, String currency) {
    // ✅ Phương thức static
    public static Money zero() {
        return new Money(BigDecimal.ZERO, "USD");
    }

    // ✅ Phương thức bổ sung
    public Money add(Money other) {
        if (!this.currency.equals(other.currency)) {
            throw new IllegalArgumentException("Different currencies");
        }
        return new Money(this.amount.add(other.amount), this.currency);
    }

    // ✅ Phương thức private (Java 16+)
    private void validate() {
        if (amount.compareTo(BigDecimal.ZERO) < 0) {
            throw new IllegalArgumentException("Negative amount");
        }
    }
}
```

**Những gì bạn không thể làm:**
- ❌ Thêm trường instance (trừ static)
- ❌ Làm Record mutable

## 🟡 Middle Level

### Cách Hoạt Động

Record cho phép thêm:
1. **Trường static** (`static fields`)
2. **Phương thức static** (`static methods`)
3. **Phương thức instance** (bất kỳ tầm nhìn nào)
4. **Phương thức private** (cho logic nội bộ)
5. **Constructor** (phải gọi canonical)

**Ví dụ:**
```java
public record User(String name, int age, String email) {
    // ✅ Trường static
    public static final int MAX_AGE = 150;

    // ✅ Factory static
    public static User anonymous() {
        return new User("Anonymous", 0, "");
    }

    // ✅ Phương thức instance
    public boolean isAdult() {
        return age >= 18;
    }

    // ✅ Phương thức private
    private boolean isValidEmail() {
        return email != null && email.contains("@");
    }

    // ✅ Canonical constructor với validation
    public User {
        if (age < 0 || age > MAX_AGE) {
            throw new IllegalArgumentException("Invalid age");
        }
    }
}
```

### Các Lỗi Thường Gặp

1. **Cố gắng thêm trường instance:**
```java
public record BadRecord() {
    // ❌ Trường instance — lỗi biên dịch
    private int mutableField = 0;

    // ✅ Chỉ static
    private static int counter = 0;
}
```

2. **Thay đổi kiểu trả về của accessor:**
```java
public record Point(int x, int y) {
    // ❌ Không thể override accessor với kiểu khác
    public String x() {  // lỗi biên dịch
        return String.valueOf(x);
    }
}
```

### Ứng Dụng Thực Tế

**1. Value object với logic:**
```java
public record Range(int min, int max) {
    public Range {
        if (min > max) {
            throw new IllegalArgumentException("min > max");
        }
    }

    public boolean contains(int value) {
        return value >= min && value <= max;
    }

    public Range intersect(Range other) {
        return new Range(
            Math.max(this.min, other.min),
            Math.min(this.max, other.max)
        );
    }
}
```

**2. Phương thức kiểu Builder:**
```java
public record Query(String table, List<String> columns, String where) {
    public Query(String table) {
        this(table, List.of("*"), null);
    }

    public Query select(String... columns) {
        return new Query(this.table, List.of(columns), this.where);
    }

    public Query where(String condition) {
        return new Query(this.table, this.columns, condition);
    }
}

// Sử dụng
Query q = new Query("users")
    .select("name", "email")
    .where("age > 18");
```

## 🔴 Senior Level

### Triển Khai Nội Bộ

**Trình biên dịch cho phép:**
- Các phương thức bổ sung không ảnh hưởng đến canonical constructor
- Phương thức instance không thay đổi cấu trúc Record
- Trường static được lưu trong class, không phải trong instance

**Ràng buộc override:**
```java
public record User(String name) {
    // Từ Java 16+ bạn CÓ THỂ override accessor với cùng chữ ký.
    // Trong các phiên bản preview điều này bị cấm.
    public String name() { return name.toUpperCase(); }  // OK trong Java 16+

    // ❌ Không thể override các phương thức final từ java.lang.Record
    // Các phương thức equals/hashCode/toString được khai báo là abstract trong java.lang.Record,
    // nhưng bạn CÓ THỂ và PHẢI override chúng.
}
```

### Đánh Đổi Kiến Trúc

**Phương thức trong Record so với tiện ích riêng biệt:**

| Cách tiếp cận                | Ưu điểm                           | Nhược điểm                    |
| --------------------- | ------------------------------- | ------------------------- |
| **Phương thức trong Record**   | Logic gần dữ liệu, thuận tiện hơn | Record trở nên "béo" hơn |
| **Tiện ích riêng biệt** | Record giữ đơn giản         | Nhiều file hơn, import   |

### Edge Cases

**1. Override equals/hashCode:**
```java
public record CaseInsensitiveString(String value) {
    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (!(o instanceof CaseInsensitiveString other)) return false;
        return Objects.equals(
            this.value.toLowerCase(),
            other.value.toLowerCase()
        );
    }

    @Override
    public int hashCode() {
        return value.toLowerCase().hashCode();
    }
}
```

**2. Constructor private:**
```java
public record UserId(UUID value) {
    // ✅ Constructor private (phải gọi canonical)
    private UserId(String value) {
        this(UUID.fromString(value));
    }

    public static UserId of(String value) {
        return new UserId(value);
    }
}
```

**3. Phương thức generic trong Record:**
```java
public record JsonNode(String json) {
    public <T> T parse(Class<T> type) {
        // Phân tích JSON
        return null;
    }
}
```

### Hiệu Năng

```
Phương thức bổ sung:
- Không có overhead bộ nhớ (phương thức nằm trong class, không phải instance)
- JIT inline phương thức như bình thường
- Không có khác biệt so với class thông thường
```

### Kinh Nghiệm Production

**Ví dụ thực tế — Domain Events:**
```java
public record OrderCreatedEvent(
    String orderId,
    List<OrderItem> items,
    Instant createdAt
) {
    public BigDecimal totalAmount() {
        return items.stream()
            .map(item -> item.price().multiply(BigDecimal.valueOf(item.quantity())))
            .reduce(BigDecimal.ZERO, BigDecimal::add);
    }

    public boolean isHighValue() {
        return totalAmount().compareTo(new BigDecimal("1000")) > 0;
    }

    public record OrderItem(String productId, int quantity, BigDecimal price) {}
}
```

### Best Practices

```java
// ✅ Thêm business logic vào Record
public record Money(BigDecimal amount, Currency currency) {
    public Money add(Money other) { /* ... */ }
    public boolean isPositive() { return amount.compareTo(BigDecimal.ZERO) > 0; }
}

// ✅ Factory static để tiện lợi
public record Point(double x, double y) {
    public static Point fromPolar(double r, double theta) {
        return new Point(r * Math.cos(theta), r * Math.sin(theta));
    }
}

// ❌ Đừng làm Record quá "béo"
// ❌ Đừng thêm trạng thái mutable
// ❌ Đừng override accessor mà không có lý do
```

## 🎯 Interview Cheat Sheet

**Cần phải biết:**
- Record có thể có trường static, phương thức static, phương thức instance
- Trường instance (không static) — bị cấm, chỉ các thành phần canonical final
- Phương thức private được hỗ trợ (Java 16+)
- Constructor phải gọi canonical qua `this(...)`
- Bạn có thể override equals/hashCode/toString, nhưng không bắt buộc
- Accessor có thể được override trong Java 16+ (bị cấm trong preview)

**Các câu hỏi phụ thường gặp:**
- **Có thể thêm một trường vào Record không?** — Chỉ static, trường instance bị cấm
- **Có thể thêm một phương thức private không?** — Có, phương thức private được hỗ trợ đầy đủ
- **Có thể nạp chồng constructor không?** — Có, nhưng constructor bổ sung phải gọi canonical
- **Có nên override equals/hashCode không?** — Chỉ khi cần logic tùy chỉnh (case-insensitive, v.v.)

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- ❌ "Bạn không thể thêm bất kỳ phương thức nào vào Record" — Bạn có thể thêm phương thức static và instance
- ❌ "Bạn có thể thêm trường mutable vào Record" — Chỉ trường static, instance bị cấm
- ❌ "Phương thức trong Record làm tăng bộ nhớ object" — Phương thức nằm trong class, không phải instance
- ❌ "Không thể override accessor" — Có thể trong Java 16+, nhưng với cùng chữ ký
