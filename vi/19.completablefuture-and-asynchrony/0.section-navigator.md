## 🎯 Tóm Tắt: Cần Biết Gì Cho Mỗi Cấp Độ

### 🟢 Junior
- CompletableFuture = kết quả bất đồng bộ + chuỗi callback
- thenApply = biến đổi, thenAccept = side effect, thenRun = hành động không có dữ liệu
- exceptionally = fallback khi lỗi, handle = xử lý cả thành công và lỗi
- join() = chặn không có checked exception, get() = chặn có checked exception

### 🟡 Middle
- supplyAsync theo mặc định → ForkJoinPool.commonPool()
- Chặn trong commonPool → thread pool starvation cho tất cả tác vụ
- allOf = chờ TẤT CẢ, anyOf = chờ CÁI ĐẦU TIÊN
- orTimeout (Java 9+) = timeout tích hợp sẵn, trong Java 8 — thủ công qua ScheduledExecutor
- exceptionallyCompose (Java 12+) = retry không chặn

### 🔴 Senior
- kích thước commonPool = availableProcessors - 1, có thể thay đổi qua System.setProperty
- ManagedBlocker thông báo cho ForkJoinPool về thao tác chặn
- obtrudeValue vi phạm hợp đồng "single completion" → race condition
- CF vs Reactive: CF = một kết quả, Reactive = stream + backpressure
- Virtual Threads (Java 21+) đơn giản hóa code chặn → CF ít quan trọng hơn
- Retry: exponential backoff + jitter ngăn thundering herd
