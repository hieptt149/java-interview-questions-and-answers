# What Is the Difference Between List<?> and List<Object>? (Sự khác biệt giữa List<?> và List<Object> là gì)

## 🟢 Junior Level

**`List<Object>`** — một kiểu cụ thể: một list các object.
- Bạn có thể thêm bất kỳ object nào (`String`, `Integer`, v.v.).
- **Bất biến (Invariant)**: `List<Object>` KHÔNG PHẢI là cha của `List<String>`.

```java
List<Object> objects = new ArrayList<>();
objects.add("Hello");
objects.add(42);  // ✅ được phép

// Nhưng:
List<String> strings = new ArrayList<>();
// process(objects);  // ✅
// process(strings);  // ❌ List<String> != List<Object>
```

**`List<?>`** — một list của kiểu không xác định.
- Bạn chỉ có thể đọc phần tử dưới dạng `Object`.
- **Không thể ghi** (trừ `null`).
- **Covariant**: chấp nhận `List<String>`, `List<Integer>`, v.v.

```java
List<?> unknown = List.of("a", "b", "c");
Object o = unknown.get(0);  // ✅
// unknown.add("x");  // ❌ không thể ghi

List<String> strings = new ArrayList<>();
process(strings);  // ✅ List<?> chấp nhận bất kỳ List parameterized nào
```

## 🟡 Middle Level

### Điều Gì Xảy Ra Tại Runtime

Sau type erasure, cả hai kiểu đều trở thành chỉ `List`. Khác biệt chỉ nằm ở kiểm tra compile-time.

```java
// List<Object> — bất biến
void process1(List<Object> list) { }
process1(new ArrayList<String>());  // ❌ lỗi biên dịch

// List<?> — covariant
void process2(List<?> list) { }
process2(new ArrayList<String>());  // ✅ OK
```

### Tại Sao List<?> Cấm Ghi

```java
List<?> unknown = new ArrayList<String>();
// unknown.add(42);  // ❌
```
Trình biên dịch không biết kiểu phần tử thực tế. Nếu việc ghi `Integer` được cho phép,
nhưng list thực tế là `List<String>` — sẽ có `ClassCastException` khi đọc.

### Raw List So Với List<?>

```java
// ❌ Raw type — tất cả kiểm tra bị tắt
List raw = new ArrayList();
raw.add("Hello");
raw.add(42);  // trình biên dịch im lặng!

// ✅ Wildcard — kiểm tra vẫn còn
List<?> wildcard = new ArrayList<String>();
wildcard.add(42);  // ❌ lỗi biên dịch
```

## 🔴 Senior Level

### Reification Và Erasure

Ở tầng bytecode, cả hai lựa chọn đơn giản là `List`. `List<?>` an toàn hơn vì
trình biên dịch chặn các thao tác không an toàn, trong khi raw type đơn giản là tắt kiểm tra.

### List<?> Không Mang Lại Lợi Thế Hiệu Năng

`List<?>` không phải chỉ đọc theo thiết kế. Trình biên dịch chặn ghi vì
nó không thể xác minh tính an toàn kiểu, không phải vì nó coi collection là bất biến.
Không có tối ưu hóa hiệu năng nào theo sau điều này.

### Capture of Wildcard

```java
// Không thể làm điều này:
void swap(List<?> list, int i, int j) {
    // var temp = list.get(i);
    // list.set(i, list.get(j));  // ❌ capture of ?
}

// Giải pháp — capture helper:
void swap(List<?> list, int i, int j) {
    swapHelper(list, i, j);
}
private <T> void swapHelper(List<T> list, int i, int j) {
    T temp = list.get(i);
    list.set(i, list.get(j));
    list.set(j, temp);
}
```

### Best Practices

```java
// ✅ List<?> cho tham số — linh hoạt tối đa
void printAll(List<?> list) { }

// ✅ List<Object> chỉ cho container không đồng nhất
List<Object> mixed = new ArrayList<>();

// ❌ Raw List — tắt tất cả kiểm tra
// ❌ List<Object> khi cần wildcard
```

## 🎯 Interview Cheat Sheet

**Cần phải biết:**
- `List<Object>` — bất biến, kiểu cụ thể, có thể thêm bất kỳ object nào
- `List<?>` — covariant, kiểu không xác định, chỉ đọc dưới dạng Object, không thể ghi
- `List<String>` KHÔNG PHẢI là subtype của `List<Object>` — generics là bất biến
- `List<?>` chấp nhận bất kỳ List parameterized nào: `List<String>`, `List<Integer>`
- `List<?>` != raw `List` — wildcard giữ lại kiểm tra, raw tắt tất cả
- Capture of wildcard — không thể get/set cho `?` trong một phương thức, cần helper `<T>`

**Các câu hỏi phụ thường gặp:**
- **Có thể thêm null vào List<?> không?** — Có, null hợp lệ cho bất kỳ kiểu nào
- **List<?> khác gì với List<Object>?** — List<?> là covariant, List<Object> là bất biến
- **Capture of wildcard là gì?** — Trình biên dịch không thể khớp kiểu `?` để ghi
- **Khi nào dùng List<Object>?** — Container không đồng nhất với các kiểu khác nhau

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- ❌ "List<?> là một list chỉ đọc" — Trình biên dịch chặn ghi do kiểu không xác định, không phải vì bất biến (immutable)
- ❌ "List<Object> chấp nhận List<String>" — Generics là bất biến, List<String> != List<Object>
- ❌ "List<?> mang lại lợi thế hiệu năng" — Không có tối ưu hóa runtime nào
- ❌ "List<?> và raw List giống nhau" — Wildcard giữ lại kiểm tra, raw tắt chúng
