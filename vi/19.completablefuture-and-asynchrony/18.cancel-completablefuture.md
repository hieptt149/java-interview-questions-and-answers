# How to Cancel CompletableFuture Execution? (Cách hủy việc thực thi CompletableFuture)

## 🟢 Junior Level

CompletableFuture có thể được hủy bằng phương thức **`cancel()`**, nhưng có những sắc thái:

```java
CompletableFuture<String> cf = CompletableFuture.supplyAsync(() -> {
    Thread.sleep(5000);
    return "Done";
});

// Hủy
boolean cancelled = cf.cancel(true);  // true = mayInterruptIfRunning

System.out.println(cf.isCancelled());  // true
```

**Quan trọng:** `cancel()` không phải lúc nào cũng dừng việc thực thi! Nó chỉ thiết lập trạng thái cancelled.

---

## 🟡 Middle Level

### Cách cancel Hoạt Động

```java
CompletableFuture<String> cf = CompletableFuture.supplyAsync(() -> {
    // Tác vụ này vẫn tiếp tục thực thi ngay cả sau khi cancel!
    Thread.sleep(5000);
    return "Done";
});

cf.cancel(false);  // không ngắt

// Tác vụ vẫn đang chạy ở background!
```

**Tại sao:** `cancel()` thiết lập kết quả thành `CancellationException`, nhưng **không ngắt thread**.

### Hủy Đúng Cách

**1. Hủy hợp tác (Cooperative cancellation):**
```java
AtomicBoolean cancelled = new AtomicBoolean(false);

CompletableFuture<String> cf = CompletableFuture.supplyAsync(() -> {
    for (int i = 0; i < 1000; i++) {
        if (cancelled.get()) {
            throw new CancellationException("Task cancelled");
        }
        // làm việc
    }
    return "Done";
});

// Hủy
cancelled.set(true);
cf.cancel(false);
```

**2. Timeout:**
```java
cf.orTimeout(5, TimeUnit.SECONDS);  // tự động hủy sau 5 giây
```

### Các Lỗi Thường Gặp

1. **Mong đợi việc ngắt:**
```java
// ❌ cancel() không ngắt thread
cf.cancel(true);  // tác vụ vẫn tiếp tục thực thi

// ✅ Hủy hợp tác
if (Thread.currentThread().isInterrupted()) {
    throw new CancellationException();
}
```

## 🔴 Senior Level

### Triển Khai Nội Bộ

```java
// Không giống FutureTask, CompletableFuture.cancel(true) cố gắng
// ngắt thread thông qua Thread.interrupt(). Nhưng điều này chỉ hoạt động
// nếu tác vụ kiểm tra Thread.interrupted() hoặc thực hiện một thao tác
// chặn phản hồi với interrupt.
// Trong thực tế, hủy hợp tác (thông qua cờ volatile) là cách tiếp cận chính.
```

### Đánh Đổi Kiến Trúc

| Cách tiếp cận          | Ưu điểm       | Nhược điểm                  |
| ----------------- | ---------- | --------------------- |
| **cancel()**      | Đơn giản     | Không ngắt    |
| **Hợp tác**   | Đáng tin cậy   | Cần thêm code   |
| **Timeout**       | Tự động  | Chỉ dựa trên thời gian       |

### Edge Cases

**1. Các CF phụ thuộc:**
```java
CompletableFuture<String> cf1 = CompletableFuture.supplyAsync(() -> "Hello");
CompletableFuture<String> cf2 = cf1.thenApply(s -> s + " World");

cf1.cancel(false);
// cf2 cũng sẽ bị hủy — nó phụ thuộc vào cf1
```

**2. Cờ interrupt:**
```java
// Kết quả phụ thuộc vào thời điểm. Nếu tác vụ đã hoàn thành — cancel()
// trả về false và isCancelled() sẽ là false. Nếu tác vụ vẫn đang chạy
// và phản hồi với interrupt — nó sẽ là true. Thread.sleep() phản hồi với interrupt.

// Thread.interrupted() có thể giúp
CompletableFuture.supplyAsync(() -> {
    while (!Thread.currentThread().isInterrupted()) {
        // làm việc
    }
    throw new CancellationException();
});
```

### Kinh Nghiệm Production

```java
public class CancellableTask {
    private volatile boolean cancelled = false;
    private CompletableFuture<String> future;

    public CompletableFuture<String> start() {
        future = CompletableFuture.supplyAsync(() -> {
            while (!cancelled) {
                // làm việc
            }
            if (cancelled) {
                throw new CancellationException();
            }
            return "Done";
        });
        return future;
    }

    public void cancel() {
        cancelled = true;
        if (future != null) {
            future.cancel(false);
        }
    }
}
```

### Best Practices

```java
// ✅ Hủy hợp tác
AtomicBoolean cancelled = new AtomicBoolean(false);

// ✅ Timeout
cf.orTimeout(5, TimeUnit.SECONDS);

// ✅ Kiểm tra cờ interrupt
if (Thread.currentThread().isInterrupted()) throw new CancellationException();

// ❌ Mong đợi cancel() ngắt thread
// ❌ Bỏ qua CancellationException
```

## 🎯 Interview Cheat Sheet

**Cần phải biết:**
- cancel(true) cố gắng ngắt thread qua Thread.interrupt(), nhưng trong thực tế không hoạt động đáng tin cậy
- Hủy hợp tác (cờ volatile / AtomicBoolean) là cách tiếp cận chính
- orTimeout() — tự động hủy dựa trên thời gian
- Khi CF gốc bị hủy, tất cả các CF phụ thuộc hoàn thành với CancellationException
- Hủy một chuỗi con KHÔNG ảnh hưởng đến CF gốc

**Các câu hỏi phụ thường gặp:**
- **cancel(true) có ngắt việc thực thi không?** — Không, nó chỉ thiết lập trạng thái. Tác vụ vẫn tiếp tục làm việc
- **Cách hủy đúng cách?** — Hợp tác: cờ AtomicBoolean + kiểm tra trong vòng lặp + cancel(false)
- **Điều gì xảy ra với các CF phụ thuộc khi hủy?** — Chúng hoàn thành với CancellationException
- **obtrudeValue để hủy?** — Không, obtrudeValue buộc thay đổi kết quả — nguy hiểm, gây ra race condition

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- "cancel(true) đảm bảo dừng tác vụ" — chỉ thiết lập cờ interrupt, tác vụ có thể bỏ qua nó
- "Sau cancel() tác vụ kết thúc ngay lập tức" — nó vẫn tiếp tục thực thi, cần hủy hợp tác
- "obtrudeValue là một cách bình thường để hủy" — vi phạm hợp đồng single-completion, gây ra race condition
