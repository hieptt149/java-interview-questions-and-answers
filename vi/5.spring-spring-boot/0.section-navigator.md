## Bảng tóm tắt: Cần biết gì cho mỗi cấp độ

### Junior
- DI = các phụ thuộc được cung cấp từ bên ngoài, không phải qua new
- Constructor injection được khuyến nghị, Field injection thì không
- Bean = đối tượng được Spring quản lý, POJO = đối tượng thông thường
- @Component, @Service, @Repository, @Controller = các annotation stereotype
- @Autowired = tiêm phụ thuộc theo kiểu
- Singleton = một cho toàn bộ context, Prototype = mới ở mỗi lần yêu cầu
- Spring Boot = auto-configuration + starter + embedded server

### Middle
- Bean Lifecycle: Instantiation -> Populate -> Initialize -> Ready -> Destroy
- @PostConstruct KHÔNG hoạt động với @Transactional (proxy chưa tồn tại)
- BPP = cơ chế để sửa đổi các bean; @Transactional, @Async hoạt động qua nó
- CGLIB (subclass) so với JDK Proxy (qua interface)
- @Transactional: rollback chỉ cho RuntimeException + Error theo mặc định
- Self-invocation: gọi một phương thức @Transactional từ cùng class KHÔNG hoạt động
- @Primary = bean mặc định, @Qualifier = chọn tường minh
- Profile = cấu hình khác nhau cho dev/test/prod

### Senior
- Cache 3 tầng cho circular dependency: singletonObjects, earlySingletonObjects, singletonFactories
- Full mode (@Configuration) = CGLIB proxy, chặn các lời gọi @Bean -> singleton. Lite mode = không có proxy, mỗi lời gọi = instance mới
- AOP: Spring AOP (proxy lúc runtime, chỉ phương thức) so với AspectJ (weaving lúc compile/load-time, bất kỳ join point nào)
- Autoconfiguration: conditional (@ConditionalOnClass, @ConditionalOnMissingBean), spring.factories -> .imports (Boot 2.7+)
- Phân giải @Autowired: byType -> @Qualifier -> @Primary -> byName
- proxyBeanMethods = false: khởi động nhanh hơn, nhưng các lời gọi giữa các @Bean tạo instance mới
- Transaction propagation: REQUIRED (mặc định), REQUIRES_NEW, NESTED, v.v.
