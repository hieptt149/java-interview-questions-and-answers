# What is EntityManager and How Does It Differ from Session (EntityManager là gì và khác với Session như thế nào)

## Overview

`EntityManager` và `Session` là hai interface để làm việc với ORM trong Java. EntityManager là interface chuẩn JPA, còn Session là triển khai đặc thù của Hibernate. Hiểu sự khác biệt giúp bạn chọn đúng abstraction.

---

## Junior Level

### EntityManager Là Gì

`EntityManager` là interface **chuẩn JPA** để làm việc với entity. Nó được định nghĩa trong đặc tả JPA và hoạt động với bất kỳ JPA provider nào (Hibernate, EclipseLink, OpenJPA).

> Lưu ý: trong Hibernate 5 / Java EE, package `javax.persistence` được dùng; trong Hibernate 6 / Jakarta EE - `jakarta.persistence`. Các ví dụ dưới đây dùng `jakarta`.

```java
// Chuẩn JPA - hoạt động với bất kỳ provider nào
@PersistenceContext
private EntityManager em;

em.persist(user);
em.merge(user);
em.remove(user);
User found = em.find(User.class, 1L);
```

### Session Là Gì

`Session` là interface **đặc thù Hibernate**. Nó cung cấp các khả năng bổ sung không có trong JPA chuẩn.

```java
// Đặc thù Hibernate
Session session = entityManager.unwrap(Session.class);
session.save(user);
session.update(user);
session.delete(user);
User found = session.get(User.class, 1L);
```

### Sự Khác Biệt Chính

|                      | EntityManager                | Session                      |
| -------------------- | ---------------------------- | ---------------------------- |
| **Chuẩn**            | JPA (jakarta.persistence)    | Hibernate (org.hibernate)    |
| **Tính portable**    | Bất kỳ JPA provider nào      | Chỉ Hibernate                |
| **Phương thức**      | persist, merge, remove, find | save, update, delete, get    |
| **Tính năng thêm**   | Không                        | doWork(), replicate(), v.v.  |

### Cách Lấy Session Từ EntityManager

```java
Session session = entityManager.unwrap(Session.class);
```

## Middle Level

### So Sánh Phương Thức

```
EntityManager (JPA)          Session (Hibernate)
-----------------           -----------------
persist()                   save()
merge()                     update(), saveOrUpdate()
remove()                    delete()
find()                      get()
createQuery()               createQuery()
createNativeQuery()         createSQLQuery()
flush()                     flush()
clear()                     clear()
contains()                  contains()
detach()                    evict()
refresh()                   refresh()
```

### Khi Nào Dùng EntityManager

```java
// Để đảm bảo tính portable giữa các JPA provider
@Repository
public class UserRepository {
    @PersistenceContext
    private EntityManager em;

    public void save(User user) {
        em.persist(user);  // phương thức chuẩn
    }
}
```

### Khi Nào Dùng Session

```java
// Cho các tính năng đặc thù Hibernate
Session session = entityManager.unwrap(Session.class);

// Truy cập Connection trực tiếp
session.doWork(connection -> {
    // Các thao tác JDBC
    PreparedStatement stmt = connection.prepareStatement("...");
});

// Các thao tác batch
session.doReturningWork(connection -> {
    // trả về kết quả
    return result;
});

// Các khả năng native của Hibernate
session.byMultipleIds(User.class)
    .multiLoad(ids);
```

### Các Phương Thức Session Bổ Sung

```java
Session session = entityManager.unwrap(Session.class);

// doWork - làm việc với Connection
session.doWork(new Work() {
    public void execute(Connection connection) {
        // Các thao tác JDBC
    }
});

// replicate - sao chép entity
session.replicate(user, ReplicationMode.OVERWRITE);

// getIdentifier - lấy ID
Serializable id = session.getIdentifier(user);

// isConnected - kiểm tra connection
boolean connected = session.isConnected();
```

## Senior Level

### Triển Khai Nội Bộ

```
// Trong Hibernate 5.2+, Session và EntityManager chia sẻ triển khai
// nội bộ. Session triển khai EntityManager, thay vì bọc nó.

EntityManager - interface từ đặc tả JPA (jakarta.persistence)
Session - interface từ Hibernate (org.hibernate)
```

### Khi Nào Dùng Session

```java
// 1. SQL native với trả về kết quả
Session session = entityManager.unwrap(Session.class);
NativeQuery<User> query = session.createNativeQuery(
    "SELECT * FROM users WHERE created_at > :date", User.class);
query.setParameter("date", date);

// 2. Multi-load (Hibernate 5.1+)
List<User> users = session.byMultipleIds(User.class)
    .enableCheckCache(true)
    .multiLoad(List.of(1L, 2L, 3L));

// 3. Scrollable results (cho dữ liệu lớn)
ScrollableResults<User> results = session.createQuery("FROM User", User.class)
    .setFetchSize(100)
    .scroll(ScrollMode.FORWARD_ONLY);

// 4. Statistics
Statistics stats = session.getSessionFactory().getStatistics();
```

### Khi Nào KHÔNG Nên Dùng Session

```java
// Nếu không cần các tính năng đặc thù Hibernate
// Nếu có thể thay đổi provider
// Cho các thao tác CRUD chuẩn
// Trong các thư viện/framework (vi phạm abstraction)
```

### Best Practices

```
EntityManager theo mặc định
unwrap(Session) khi cần các tính năng Hibernate
Các phương thức chuẩn để đảm bảo tính portable
Session cho các thao tác batch/native
Session cho statistics và monitoring

Session khi không cần các tính năng Hibernate
Trộn lẫn mà không có lý do
unwrap() trong mỗi phương thức (tốt hơn nên trích xuất)
Dùng Session trực tiếp trong các thư viện
```

## Interview Cheat Sheet

**Cần phải biết:**
- EntityManager - chuẩn JPA (jakarta.persistence), hoạt động với bất kỳ provider nào
- Session - interface đặc thù Hibernate, các khả năng bổ sung
- Session có được thông qua entityManager.unwrap(Session.class)
- Phương thức EntityManager: persist, merge, remove, find; Session: save, update, delete, get
- Session cung cấp: doWork() (JDBC), multi-load, scrollable results, statistics
- EntityManager theo mặc định, Session khi cần các tính năng Hibernate

**Các câu hỏi phụ thường gặp:**
- **Khi nào dùng Session?** SQL native với trả về kết quả, multi-load, scrollable results, statistics, các thao tác batch
- **Khi nào KHÔNG nên dùng Session?** CRUD chuẩn, có thể thay đổi provider, thư viện/framework
- **Tại sao cần doWork()?** Truy cập trực tiếp Connection JDBC cho các thao tác JPA không hỗ trợ
- **Điều gì thay đổi trong Hibernate 5.2+?** Session và EntityManager chia sẻ triển khai nội bộ

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- "Tôi luôn dùng Session thay vì EntityManager" - ràng buộc vào Hibernate
- "Tôi trộn lẫn chúng mà không có lý do" - vi phạm abstraction JPA
- "unwrap() trong mỗi phương thức" - tốt hơn nên trích xuất vào một component riêng
- "Session trong các thư viện" - vi phạm tính portable
