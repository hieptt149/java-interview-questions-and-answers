# What Does orTimeout() Method Do in Java 9+? (Phương thức orTimeout() làm gì trong Java 9+)

## 🟢 Junior Level

**`orTimeout()`** — hoàn thành một CompletableFuture với `TimeoutException` nếu nó chưa hoàn thành trong khoảng thời gian được chỉ định.

```java
CompletableFuture<String> cf = fetchDataAsync();

// Timeout 5 giây
cf.orTimeout(5, TimeUnit.SECONDS)
  .thenAccept(result -> System.out.println(result))
  .exceptionally(ex -> {
      // TimeoutException nếu không xong trong vòng 5 giây
      System.out.println("Timeout!");
      return "fallback";
  });
```

---

## 🟡 Middle Level

### Cách Hoạt Động

```java
cf.orTimeout(5, TimeUnit.SECONDS);

// Nếu cf hoàn thành trong vòng 5 giây — OK
// Nếu không — CF hoàn thành với TimeoutException
```

**completeOnTimeout — lựa chọn thay thế:**
```java
// orTimeout — ngoại lệ khi timeout
cf.orTimeout(5, TimeUnit.SECONDS);

// completeOnTimeout — giá trị fallback khi timeout
cf.completeOnTimeout("default", 5, TimeUnit.SECONDS);
```

### Các Lỗi Thường Gặp

1. **Tác vụ vẫn tiếp tục thực thi:**
```java
cf.orTimeout(5, TimeUnit.SECONDS);

// CF hoàn thành với TimeoutException
// Nhưng tác vụ trong executor vẫn tiếp tục chạy!
```

## 🔴 Senior Level

### Triển Khai Nội Bộ

```java
public CompletableFuture<T> orTimeout(long timeout, TimeUnit unit) {
    if (result == null)
        whenComplete(timeoutFuture(timeout, unit));
    return this;
}

// Dùng ScheduledExecutorService cho việc hoàn thành trễ
```

### Hiệu Năng

```
Overhead của orTimeout:
(Java 21, benchmark đơn luồng). Để so sánh: một lời gọi HTTP điển hình
mất 10-100ms, vì vậy overhead của timeout (~1μs) chiếm dưới 0.01%.
```

### Best Practices

```java
// ✅ orTimeout cho Java 9+
cf.orTimeout(5, TimeUnit.SECONDS);

// ✅ completeOnTimeout cho fallback
cf.completeOnTimeout(defaultValue, 5, TimeUnit.SECONDS);

// ❌ Mong đợi tác vụ bị hủy
// ❌ Timeout mà không xử lý TimeoutException
```

## 🎯 Interview Cheat Sheet

**Cần phải biết:**
- orTimeout(timeout, unit) — hoàn thành CF với TimeoutException khi vượt quá thời gian
- completeOnTimeout(value, timeout, unit) — lựa chọn thay thế với một giá trị fallback
- Nội bộ dùng ScheduledExecutorService cho việc hoàn thành trễ
- Timeout KHÔNG hủy tác vụ — nó vẫn tiếp tục làm việc trong executor
- whenComplete(cancel) khi hoàn thành bình thường sẽ hủy tác vụ đã lập lịch

**Các câu hỏi phụ thường gặp:**
- **orTimeout có hủy tác vụ trong executor không?** — Không, CF hoàn thành, tác vụ vẫn tiếp tục làm việc
- **orTimeout vs completeOnTimeout?** — orTimeout ném ra TimeoutException, completeOnTimeout trả về fallback
- **Overhead của orTimeout?** — ~1μs, không đáng kể so với một lời gọi HTTP (10-100ms)
- **Lựa chọn thay thế cho Java 8?** — ScheduledExecutorService + anyOf(cf, timeoutCF)

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- "orTimeout dừng tác vụ" — chỉ hoàn thành CF, tác vụ vẫn tiếp tục chạy
- "orTimeout có sẵn trong Java 8" — chỉ có từ Java 9
- "TimeoutException có thể bỏ qua" — cần fallback hoặc retry
