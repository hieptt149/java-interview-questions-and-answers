# What Are Generics in Java? (Generics trong Java là gì)

## 🟢 Junior Level

**Generics** là một cơ chế trong Java cho phép tạo class, interface, và phương thức làm việc với **các kiểu khác nhau** trong khi vẫn duy trì **tính an toàn kiểu (type safety)**.

Ý tưởng chính: bạn viết code một lần, và nó hoạt động với bất kỳ kiểu nào.

```java
// Không có generics (trước Java 5)
List list = new ArrayList();
list.add("Hello");
String s = (String) list.get(0);  // cần cast!

// Có generics (Java 5+)
List<String> list = new ArrayList<>();
list.add("Hello");
String s = list.get(0);  // không cần cast!
```

**Tại sao chúng cần thiết:**
1. **Tính an toàn kiểu** — lỗi được bắt tại compile time
2. **Không cần cast** — code sạch hơn và an toàn hơn
3. **Khả năng tái sử dụng** — một đoạn code cho các kiểu khác nhau

**Ví dụ:**
```java
// Một class hoạt động với bất kỳ kiểu nào
public class Box<T> {
    private T value;

    public void set(T value) { this.value = value; }
    public T get() { return value; }
}

Box<String> stringBox = new Box<>();
stringBox.set("Hello");

Box<Integer> intBox = new Box<>();
intBox.set(42);
```

## 🟡 Middle Level

### Cách Hoạt Động

**Type parameter** (`<T>`) là một placeholder cho một kiểu được chỉ định lúc sử dụng:

```java
// Khai báo
public class Box<T> {
    private T value;
    public void set(T value) { this.value = value; }
    public T get() { return value; }
}

// Sử dụng
Box<String> box = new Box<>();  // T = String
box.set("Hello");
String s = box.get();  // tự động là String, không cần cast
```

**Nhiều tham số:**
```java
public class Pair<K, V> {
    private K key;
    private V value;

    public Pair(K key, V value) {
        this.key = key;
        this.value = value;
    }

    public K getKey() { return key; }
    public V getValue() { return value; }
}

Pair<String, Integer> pair = new Pair<>("age", 25);
```

### Bounded Type Parameters

Bạn có thể ràng buộc kiểu:
```java
// Chỉ Number và các lớp con của nó
public class NumberBox<T extends Number> {
    private T value;
    public double doubleValue() { return value.doubleValue(); }
}

NumberBox<Integer> intBox = new NumberBox<>();  // ✅
NumberBox<String> strBox = new NumberBox<>();   // ❌ lỗi
```

### Các Lỗi Thường Gặp

1. **Dùng raw type:**
```java
// ❌ Raw type — không có tính an toàn kiểu
List list = new ArrayList();
list.add("Hello");
list.add(42);  // trình biên dịch không phàn nàn, nhưng đây là bug!

// ✅ Parameterized type
List<String> list = new ArrayList<>();
list.add("Hello");
// list.add(42);  // lỗi biên dịch
```

2. **Mong đợi kiểu nguyên thủy hoạt động:**
```java
// ❌ Kiểu nguyên thủy không thể dùng làm type parameter
List<int> list = new ArrayList<>();  // lỗi biên dịch

// ✅ Dùng wrapper class
List<Integer> list = new ArrayList<>();
```

### Ứng Dụng Thực Tế

**1. Phương thức generic:**
```java
public static <T> T getFirst(List<T> list) {
    return list.isEmpty() ? null : list.get(0);
}

List<String> strings = List.of("a", "b", "c");
String first = getFirst(strings);  // T được suy ra là String
```

**2. Interface generic:**
```java
public interface Repository<T, ID> {
    Optional<T> findById(ID id);
    List<T> findAll();
    T save(T entity);
}

public class UserRepository implements Repository<User, Long> {
    public Optional<User> findById(Long id) { /* ... */ }
}
```

## 🔴 Senior Level

### Triển Khai Nội Bộ

**Type Erasure:**
```java
// Source code
public class Box<T> {
    private T value;
    public void set(T value) { this.value = value; }
    public T get() { return value; }
}

// Sau khi biên dịch (type erasure)
public class Box {
    private Object value;  // T -> Object (bound trên)
    public void set(Object value) { this.value = value; }
    public Object get() { return value; }
}

// Trình biên dịch thêm cast khi sử dụng
Box<String> box = new Box<>();
box.set("Hello");
String s = (String) box.get();  // cast ngầm định
```

**Bounded type erasure:**
```java
public class NumberBox<T extends Number> {
    private T value;
}

// Sau erasure: T -> Number (bound đầu tiên)
public class NumberBox {
    private Number value;
}
```

### Đánh Đổi Kiến Trúc

**Type Erasure:**

| Ưu điểm                                                   | Nhược điểm                                     |
| ------------------------------------------------------- | ------------------------------------------ |
| Tương thích nhị phân (code Java 5 hoạt động với Java 1.4) | Không thể tạo `new T()`                   |
| Không có overhead runtime                                     | Không thể kiểm tra `obj instanceof T`        |
|                                                         | Vấn đề với mảng (`new T[]`)           |
|                                                         | Cần bridge method để giữ tính đa hình |

// Bridge Method — một phương thức tổng hợp mà trình biên dịch thêm vào
// để giữ tính đa hình sau type erasure.

### Edge Cases

**1. Tạo mảng generic:**
```java
// ❌ Không thể tạo mảng của kiểu generic
public class Box<T> {
    private T[] array = new T[10];  // lỗi biên dịch
}

// ✅ Giải pháp — mảng Object với cast
public class Box<T> {
    private T[] array = (T[]) new Object[10];
    // ⚠️ Nguy hiểm: nếu bạn trả về mảng này ra bên ngoài, bên gọi có thể nhận ClassCastException.
    // ArrayList dùng Object[] nội bộ, nhưng kiểm soát tất cả các lần ghi — điều này an toàn.
    // Code của bạn — không phải lúc nào cũng vậy.
}
```

**2. Instanceof với generics:**
```java
// ❌ Không thể làm
if (obj instanceof Box<String>) { }  // lỗi biên dịch

// ✅ Có thể — raw type hoặc wildcard
if (obj instanceof Box<?>) { }  // OK
```

**3. Ngữ cảnh static:**
```java
public class Box<T> {
    // ❌ Trường static không thể dùng T
    private static T value;  // lỗi biên dịch

    // ✅ Phương thức generic — T riêng của nó
    public static <E> void process(E item) { }
}
```

### Hiệu Năng

```
Overhead của type erasure:
- Runtime: Overhead bằng không (không có kiểm tra bổ sung)
- Bộ nhớ: Không có dữ liệu bổ sung
- Cast: Cast ngầm định khi truy cập (không đáng kể)

Box<Integer> box = new Box<>();
box.set(42);          // autoboxing int -> Integer
Integer val = box.get();  // cast + unboxing

Tổng overhead: autoboxing + cast (~1-2 ns)
```

### Kinh Nghiệm Production

**Generic Repository:**
```java
public interface BaseEntity {
    Long getId();
}

public interface Repository<T extends BaseEntity, ID extends Serializable> {
    Optional<T> findById(ID id);
    List<T> findAll(Pageable pageable);
    <S extends T> S save(S entity);
    long count();
    boolean existsById(ID id);
}

public abstract class JpaRepository<T extends BaseEntity, ID extends Serializable>
    implements Repository<T, ID> {

    private final Class<T> entityType;
    private final EntityManager em;

    protected JpaRepository(Class<T> entityType, EntityManager em) {
        this.entityType = entityType;
        this.em = em;
    }

    public Optional<T> findById(ID id) {
        return Optional.ofNullable(em.find(entityType, id));
    }
}
```

### Best Practices

```java
// ✅ Dùng generics cho collection
List<User> users = new ArrayList<>();

// ✅ Phương thức generic để tái sử dụng
public static <T> List<T> filter(List<T> list, Predicate<T> predicate) {
    return list.stream().filter(predicate).toList();
}

// ✅ Bounded type cho ràng buộc
public static <T extends Comparable<T>> T max(List<T> list) {
    return list.stream().max(Comparable::compareTo).orElse(null);
}

// ❌ Raw type
// ❌ new T[] hoặc new T()
// ❌ instanceof T
```

## 🎯 Interview Cheat Sheet

**Cần phải biết:**
- Generics xuất hiện trong Java 5 (JEP 14) để đảm bảo tính an toàn kiểu khi làm việc với collection
- Type parameter: `<T>`, `<K, V>`, `<E>` — placeholder cho kiểu
- Bounded type parameter: `<T extends Number>` — ràng buộc kiểu
- Type erasure — trình biên dịch loại bỏ thông tin kiểu, T -> Object hoặc bound
- Raw type — sử dụng không có type argument, tắt việc kiểm tra kiểu
- Kiểu nguyên thủy không thể dùng: `List<int>` — lỗi, cần `List<Integer>`

**Các câu hỏi phụ thường gặp:**
- **Tại sao cần generics?** — Tính an toàn kiểu tại compile time, loại bỏ cast, tái sử dụng code
- **Type erasure là gì?** — Sau khi biên dịch T được thay bằng Object hoặc bound, JVM không thấy generics
- **Có thể instanceof T không?** — Không, `obj instanceof T` — lỗi biên dịch do type erasure
- **Tại sao List<String> không kế thừa từ List<Object>?** — Generics là bất biến (invariant), wildcard được dùng cho tính linh hoạt

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- ❌ "Generics hoạt động tại runtime" — Type erasure loại bỏ kiểu tại compilation
- ❌ "List<String> là subtype của List<Object>" — Generics là bất biến
- ❌ "Bạn có thể tạo new T()" — Type erasure không cho phép biết constructor của T
- ❌ "Kiểu nguyên thủy có thể dùng làm tham số" — Chỉ wrapper class (Integer, Double)
