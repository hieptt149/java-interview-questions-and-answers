# Can You Override Constructor in Record? (Có thể override constructor trong Record không)

## 🟢 Junior Level

**Có, nhưng có ràng buộc.** Bạn có thể thêm constructor riêng vào một Record, nhưng nó **phải gọi canonical constructor** (thông qua `this(...)`).

**Hai cách:**

```java
// Cách 1: Dạng đầy đủ
public record User(String name, int age) {
    // Constructor riêng — phải gọi this(...)
    public User(String name) {
        this(name, 0);  // gọi canonical constructor
    }
}

// Cách 2: Compact constructor (chỉ validation)
public record User(String name, int age) {
    public User {
        if (age < 0) {
            throw new IllegalArgumentException("Invalid age");
        }
    }
}
```

**Bạn không thể:**
- ❌ Tạo một constructor không gọi `this(...)`
- ❌ Thêm một constructor mà không gọi canonical

## 🟡 Middle Level

### Cách Hoạt Động

**1. Canonical constructor (tự động sinh):**
```java
public record Point(int x, int y) {}

// Tự động sinh:
public Point(int x, int y) {
    this.x = x;
    this.y = y;
}
```

**2. Constructor bổ sung:**
```java
public record Point(int x, int y) {
    // Phải gọi this(...) ở dòng đầu tiên
    public Point() {
        this(0, 0);  // ✅ OK
    }

    public Point(int value) {
        this(value, value);  // ✅ OK
    }

    // ❌ public Point(String s) { } — không có this()!
}
```

**3. Compact constructor (chỉ validation):**
```java
public record Email(String value) {
    // Compact constructor — KHÔNG chứa chữ ký
    public Email {
        if (value == null || !value.contains("@")) {
            throw new IllegalArgumentException("Invalid email");
        }
    }
}

// Sử dụng
Email e1 = new Email("test@example.com");  // ✅ OK
Email e2 = new Email("invalid");  // ném ra IllegalArgumentException
```

### Các Lỗi Thường Gặp

1. **Quên gọi `this(...)`:**
```java
public record User(String name) {
    // ❌ lỗi biên dịch — không có lời gọi this()
    public User() {
        System.out.println("Created");
    }

    // ✅ Đúng
    public User() {
        this("Anonymous");
    }
}
```

2. **Compact constructor với gán giá trị:**
```java
public record User(String name) {
    // Compact constructor CÓ THỂ gán lại tham số:
    // name = name.toUpperCase() — hợp lệ trong Java 16+.
    // Việc gán xảy ra trước khi gán trường ngầm định.
    public User {
        name = name.toUpperCase();  // OK trong Java 16+
    }
}
```

### Ứng Dụng Thực Tế

**1. Validation:**
```java
public record Money(BigDecimal amount, Currency currency) {
    public Money {
        Objects.requireNonNull(currency, "Currency cannot be null");
        if (amount.compareTo(BigDecimal.ZERO) < 0) {
            throw new IllegalArgumentException("Negative amount");
        }
    }
}
```

**2. Chuẩn hóa dữ liệu:**
```java
public record Email(String value) {
    public Email {
        value = value.toLowerCase().trim();  // chuẩn hóa
    }
}
```

**3. Constructor factory:**
```java
public record Range(int min, int max) {
    public Range(int value) {
        this(value, value);
    }

    public Range(String rangeStr) {
        // phân tích "1-100" -> min=1, max=100
        String[] parts = rangeStr.split("-");
        this(Integer.parseInt(parts[0]), Integer.parseInt(parts[1]));
    }
}
```

## 🔴 Senior Level

### Triển Khai Nội Bộ

**Trình biên dịch sinh ra:**
```java
// Source code
public record User(String name, int age) {
    public User {
        if (age < 0) throw new IllegalArgumentException();
    }

    public User(String name) {
        this(name, 0);
    }
}

// Sau desugar:
public final class User extends Record {
    private final String name;
    private final int age;

    // Canonical constructor + validation compact
    public User(String name, int age) {
        if (age < 0) throw new IllegalArgumentException();
        this.name = name;
        this.age = age;
    }

    // Constructor bổ sung
    public User(String name) {
        this(name, 0);
    }
}
```

### Đánh Đổi Kiến Trúc

**Compact constructor so với constructor đầy đủ:**

| Cách tiếp cận         | Ưu điểm                            | Nhược điểm                    |
| -------------- | -------------------------------- | ------------------------- |
| **Compact** | Ngắn gọn, chỉ validation       | Không thể thay đổi tham số |
| **Đầy đủ**     | Linh hoạt, có thể thay đổi tham số | Nhiều code hơn, nguy cơ bug  |

### Edge Cases

**1. Chuỗi constructor (chaining):**
```java
public record Config(String host, int port, String protocol) {
    public Config(String host, int port) {
        this(host, port, "http");
    }

    public Config(String host) {
        this(host, 8080);
    }

    public Config() {
        this("localhost");
    }

    public Config {
        if (port < 1 || port > 65535) {
            throw new IllegalArgumentException("Invalid port");
        }
    }
}
```

**2. Chuẩn hóa với object mutable:**
```java
public record User(List<String> emails) {
    public User {
        // Bản sao phòng thủ (defensive copy) cho collection mutable
        emails = new ArrayList<>(emails);
    }
}
```

**3. Constructor với ngoại lệ:**
```java
public record JsonNode(String json) {
    public JsonNode {
        try {
            // Xác thực JSON
            Json.parse(json);
        } catch (JsonParseException e) {
            throw new IllegalArgumentException("Invalid JSON", e);
        }
    }
}
```

### Hiệu Năng

```
Constructor của Record:
- Compact constructor: validation nội tuyến
- Constructor đầy đủ: ủy quyền (một lời gọi)
- Khác biệt không đáng kể (< 1 ns)
- JIT inline cả hai cách tiếp cận
```

### Kinh Nghiệm Production

**DTO với validation:**
```java
public record CreateUserRequest(
    @NotBlank String name,
    @Email String email,
    @Min(18) int age
) {
    public CreateUserRequest {
        // Validation bổ sung sau Bean Validation
        if (name.length() > 100) {
            throw new IllegalArgumentException("Name too long");
        }
    }
}
```

**Domain object:**
```java
public record OrderId(String value) {
    private static final Pattern UUID_PATTERN =
        Pattern.compile("^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$");

    public OrderId {
        if (!UUID_PATTERN.matcher(value).matches()) {
            throw new IllegalArgumentException("Invalid UUID format");
        }
        value = value.toLowerCase();  // chuẩn hóa
    }

    public static OrderId generate() {
        return new OrderId(UUID.randomUUID().toString());
    }
}
```

### Best Practices


## 🎯 Interview Cheat Sheet

**Cần phải biết:**
- Bạn có thể thêm constructor riêng vào Record, nhưng nó phải gọi canonical qua `this(...)`
- Compact constructor — dạng không có chữ ký, chỉ dùng cho validation và chuẩn hóa
- Compact constructor được inline vào canonical trước khi gán trường
- Trong compact constructor bạn có thể sửa đổi tham số trước khi gán: `name = name.toUpperCase()`
- Không thể ném checked exception từ compact constructor (canonical không khai báo throws)
- Bạn có thể có nhiều constructor bổ sung + một compact constructor

**Các câu hỏi phụ thường gặp:**
- **Compact constructor khác gì so với thông thường?** — Compact không có chữ ký, chỉ validation; thông thường phải gọi `this(...)`
- **Có thể chuẩn hóa dữ liệu trong constructor không?** — Có, trong compact bạn có thể: `name = name.trim()`
- **Điều gì xảy ra nếu constructor không gọi this(...)?** — Lỗi biên dịch: "constructor must call this(...)"
- **Có thể ném checked exception từ compact constructor không?** — Không, phải bọc trong unchecked

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- ❌ "Compact constructor gán trường qua this.field" — Dùng tên tham số, không phải this.field
- ❌ "Bạn có thể tạo constructor không gọi this()" — Gọi canonical constructor là bắt buộc
- ❌ "Compact constructor có thể thêm trường" — Không thể thêm trường instance
- ❌ "Constructor có thể ném checked exception" — Canonical constructor không khai báo throws
