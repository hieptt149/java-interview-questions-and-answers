# Difference between @Component, @Service, @Repository, @Controller? (Sự khác nhau giữa @Component, @Service, @Repository, @Controller?)

## Junior Level

Tất cả các annotation này đều tạo bean, nhưng cho các tầng (layer) khác nhau của ứng dụng:

| Annotation           | Dùng cho gì      | Đặc điểm                             |
| ------------------- | ------------- | ----------------------------------- |
| **@Component**      | Bean chung     | Annotation cơ sở                   |
| **@Service**        | Logic nghiệp vụ | Marker mang tính ngữ nghĩa                 |
| **@Repository**     | Truy cập database   | Tự động dịch exception |
| **@Controller**     | Web MVC       | Trả về View (HTML)              |
| **@RestController** | REST API      | Trả về JSON                     |

```java
@Repository
public class UserRepository { }

@Service
public class UserService { }

@RestController
public class UserController { }
```

## Middle Level

### @Repository — Dịch Exception (Exception Translation)

```java
Việc dịch được thực hiện KHÔNG PHẢI bởi bản thân annotation @Repository, mà bởi PersistenceExceptionTranslationPostProcessor.
Nó tạo một proxy bao quanh bean và chặn các exception. Không có
JPA/Hibernate được kết nối thì sẽ KHÔNG có việc dịch - các exception đi qua nguyên trạng.
```

### @RestController

```java
// @RestController = @Controller + @ResponseBody. @ResponseBody nói với Spring: đừng tìm
// View (template HTML), mà hãy serialize đối tượng trả về thành HTTP response (thường là JSON qua Jackson).

// @Controller -> trả về View (HTML)
@Controller
public class PageController {
    @GetMapping("/page")
    public String page() { return "page.html"; }  // View
}

// @RestController -> trả về JSON
@RestController
public class ApiController {
    @GetMapping("/api/user")
    public User user() { return new User(); }  // JSON
}
```

### Các Pointcut của AOP

```java
// Áp dụng aspect chỉ cho các service:
@Before("within(@org.springframework.stereotype.Service *)")
public void logServiceCall() { }
```

## Senior Level

### PersistenceExceptionTranslationPostProcessor

```
@Repository -> proxy -> chặn các exception
  -> PersistenceExceptionTranslator
    -> JpaDialect, HibernateExceptionTranslator
      -> Dịch thành DataAccessException
```

### Tối ưu hóa Component Scanning

```
spring-context-indexer:
  -> META-INF/spring.components lúc biên dịch
  -> Spring đọc danh sách thay vì quét
  -> +50% tốc độ khởi động
```

### Overhead của Proxy

```
@Repository tạo một proxy để dịch exception.
Overhead được tính bằng nanosecond - không đáng kể với hầu hết ứng dụng.
Chỉ quan trọng ở >100K lời gọi/giây.
```

### Kinh nghiệm Production

**Tình huống thực tế: Repository không dịch**
```
@Repository trên class
  -> Lời gọi phương thức self-invocation
  -> Proxy không hoạt động
  -> SQL Exception thay vì DataAccessException

Giải pháp: tách ra một bean riêng
```

### Best Practices

1. **@Component** -> cơ sở, ít dùng
2. **@Service** -> logic nghiệp vụ
3. **@Repository** -> chỉ cho DAO
4. **@RestController** -> REST API
5. **AOP** -> các pointcut chính xác theo stereotype
6. **Tránh** @Component cho DAO/Controller

### Tóm tắt cho Senior

- **@Repository** -> dịch exception qua proxy
- **@Service** -> ngữ nghĩa, các AOP pointcut
- **@RestController** -> JSON, không phải View
- **Overhead của proxy** -> 1-5 microsecond mỗi lời gọi
- **Self-invocation** -> proxy không hoạt động
- **spring-context-indexer** -> tăng tốc quét

## Interview Cheat Sheet

**Cần phải biết:**
- Cả 4 annotation đều là stereotype của @Component, nhưng cho các tầng kiến trúc khác nhau
- @Repository: PersistenceExceptionTranslationPostProcessor dịch SQLException -> DataAccessException
- @Service: marker ngữ nghĩa + điểm cho AOP (within(@Service *))
- @Controller: trả về View (template HTML), @RestController = @Controller + @ResponseBody -> JSON
- Việc dịch exception chỉ hoạt động khi có JPA/Hibernate được kết nối và qua proxy
- Self-invocation (gọi phương thức của chính mình bên trong một bean) không đi qua proxy — exception không được dịch
- Overhead của proxy: 1-5 microsecond mỗi lời gọi, đáng kể ở >100K lời gọi/giây

**Các câu hỏi phụ thường gặp:**
- *Tại sao @Repository dịch exception còn @Service thì không?* — PersistenceExceptionTranslationPostProcessor chỉ tạo một proxy bao quanh @Repository.
- *Điều gì xảy ra với self-invocation trong @Repository?* — Proxy sẽ không hoạt động, SQLException sẽ không được dịch.
- *Sự khác nhau giữa @Controller và @RestController là gì?* — @Controller trả về tên View, @RestController serialize đối tượng thành JSON (@ResponseBody).
- *Tại sao cần các annotation khác nhau nếu tất cả = @Component?* — Ngữ nghĩa, các AOP pointcut, xử lý tự động (exception, web).

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- "@Service cũng dịch exception" — không, chỉ @Repository.
- "@RestController là một annotation riêng biệt không liên quan đến @Controller" — không, nó là @Controller + @ResponseBody.
- "Proxy của @Repository hoạt động khi self-invocation" — không, Spring AOP không chặn các lời gọi nội bộ.
- "@Component ổn cho DAO" — không, dùng @Repository để dịch exception.
