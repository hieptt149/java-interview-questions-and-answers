# How to Properly Use @OneToMany and @ManyToOne (Cách dùng đúng @OneToMany và @ManyToOne)

## Overview

`@OneToMany` và `@ManyToOne` là các annotation phổ biến nhất cho mối quan hệ trong JPA. Dùng đúng cách là quan trọng cho hiệu năng và tính đúng đắn của database.

---

## Junior Level

### @ManyToOne Và @OneToMany Là Gì

**`@ManyToOne`** - nhiều order với một user.

**`@OneToMany`** - một user với nhiều order.

```java
@Entity
public class Order {
    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "user_id")
    private User user;
}

@Entity
public class User {
    @OneToMany(mappedBy = "user", fetch = FetchType.LAZY)
    private List<Order> orders;
}
```

### Các Quy Tắc Quan Trọng

1. **`mappedBy`** - chỉ ra rằng mối quan hệ được quản lý ở phía bên kia
2. **`@JoinColumn`** - chỉ định cột khóa ngoại
3. **LAZY** - dùng cho cả hai phía

### Ví Dụ

```java
// Order - phía owner (chứa FK)
@Entity
public class Order {
    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "user_id")
    private User user;
}

// User - phía inverse (không chứa FK)
@Entity
public class User {
    @OneToMany(mappedBy = "user", fetch = FetchType.LAZY)
    private List<Order> orders = new ArrayList<>();
}
```

## Middle Level

### Mối Quan Hệ Hai Chiều

```java
// Phía owner - Order (chứa cột FK)
@Entity
public class Order {
    @Id
    private Long id;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "user_id")
    private User user;
}

// Phía inverse - User
@Entity
public class User {
    @Id
    private Long id;

    @OneToMany(mappedBy = "user", cascade = CascadeType.ALL, orphanRemoval = true)
    private List<Order> orders = new ArrayList<>();

    // Phương thức helper - bắt buộc!
    public void addOrder(Order order) {
        orders.add(order);
        order.setUser(this);  // quan trọng!
    }

    public void removeOrder(Order order) {
        orders.remove(order);
        order.setUser(null);  // quan trọng!
    }
}
```

### Tại Sao Phương Thức Helper Bắt Buộc

```java
// Không có phương thức helper
User user = new User();
Order order = new Order();
user.getOrders().add(order);
// order.getUser() = null! -> FK không được đặt

// Có phương thức helper
User user = new User();
Order order = new Order();
user.addOrder(order);  // đặt cả hai phía
// order.getUser() == user OK
```

### Các Lỗi Thường Gặp

```java
// mappedBy ở phía inverse (User - inverse, Order - owner):
@OneToMany(mappedBy = "user")  // đúng: User - phía inverse
private List<Order> orders;

// mappedBy ở phía owner (Order) - VÔ DỤNG:
// @ManyToOne(mappedBy = ...) - thuộc tính như vậy không tồn tại trên @ManyToOne

// Không khởi tạo collection
private List<Order> orders;  // NullPointerException khi add
private List<Order> orders = new ArrayList<>();  // đúng

// EAGER cho collection
@OneToMany(fetch = FetchType.EAGER)  // N+1 problem
private List<Order> orders;

// Điều gì xảy ra trong SQL với EAGER trên collection:
// SELECT * FROM users;                    -- 1 truy vấn
// SELECT * FROM orders WHERE user_id = 1; -- N truy vấn (một cho mỗi user)
// -- Tổng: 1 + N truy vấn thay vì 1 JOIN
```

## Senior Level

### Triển Khai Nội Bộ

```
@ManyToOne - cột FK trong table Order
@OneToMany(mappedBy) - không có cột FK, đây là phía inverse

Phía owner (@ManyToOne):
- Quản lý cột FK
- persist(order) -> INSERT với user_id
- merge(order) -> UPDATE user_id

Phía inverse (@OneToMany(mappedBy)):
- Không quản lý FK
- mappedBy = tên trường ở phía owner
- Chỉ cho việc điều hướng ngược
```

### Unidirectional vs Bidirectional

```java
// Unidirectional @ManyToOne (chỉ Order -> User)
@Entity
public class Order {
    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "user_id")
    private User user;
}

// Unidirectional @OneToMany (chỉ User -> Orders)
@Entity
public class User {
    @OneToMany
    @JoinColumn(name = "user_id")  // FK ở phía Order
    private List<Order> orders;
}

// Bidirectional - cả hai hướng
// Order biết về User, User biết về Orders
// Yêu cầu đồng bộ cả hai phía
```

### Khi Nào Dùng Cái Gì

```
Unidirectional @ManyToOne:
- Đơn giản hơn, không cần đồng bộ
- Khi không cần điều hướng User -> Orders
- Ít code hơn

Bidirectional:
- Khi cần điều hướng cả hai hướng
- Khi cần cascade với orphanRemoval
- Yêu cầu phương thức helper
```

### Tối Ưu

```java
// @JoinColumn trên @OneToMany unidirectional (Hibernate 6+)
@Entity
public class User {
    @OneToMany
    @JoinColumn(name = "user_id",
                foreignKey = @ForeignKey(name = "fk_user_orders"),
                referencedColumnName = "id")
    private List<Order> orders;
}
// Hibernate 6+: không tạo join table
```

### Best Practices

```
LAZY cho cả hai phía
Phương thức helper để đồng bộ
mappedBy ở phía inverse
Khởi tạo các collection
@JoinColumn ở phía owner
orphanRemoval cho các child composite

EAGER cho collection
Không có phương thức helper
mappedBy ở phía owner
Không khởi tạo collection
Unidirectional @OneToMany với join table
```

## Interview Cheat Sheet

**Cần phải biết:**
- @ManyToOne - phía owner (chứa FK), @OneToMany(mappedBy) - phía inverse (không có FK)
- LAZY cho cả hai phía - quy tắc vàng
- Phương thức helper bắt buộc cho bidirectional: addOrder/removeOrder đồng bộ cả hai phía
- mappedBy trỏ đến trường ở phía owner - nếu không có nó Hibernate tạo một join table
- Luôn khởi tạo collection: new ArrayList<>() - nếu không sẽ NullPointerException
- Unidirectional @OneToMany tạo một join table (trước Hibernate 6), trong Hibernate 6+ có thể dùng @JoinColumn

**Các câu hỏi phụ thường gặp:**
- **Tại sao phương thức helper bắt buộc?** Chỉ thêm vào collection mà không setUser() -> FK = null, mất đồng bộ
- **Điều gì nếu không có mappedBy?** Hibernate tạo một join table không cần thiết - overhead thêm
- **Tại sao EAGER cho collection xấu?** N+1 problem: tải tất cả child cho mỗi parent
- **Khi nào dùng @OneToMany unidirectional?** Khi không cần điều hướng User -> Orders, đơn giản hơn

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- "EAGER cho @OneToMany" - N+1 problem chắc chắn
- "Không có phương thức helper cho bidirectional" - mất đồng bộ, FK không được đặt
- "mappedBy ở phía owner" - thuộc tính như vậy không tồn tại trên @ManyToOne
- "Collection không khởi tạo" - NullPointerException khi add
