# What is the difference between Iterator and ListIterator? (Sự khác nhau giữa Iterator và ListIterator là gì?)

## 🟢 Junior Level

**Iterator** — để iterate qua bất kỳ collection nào (chỉ tiến về phía trước).
**ListIterator** — cho các list (tiến và lùi).

```java
// Iterator: làm việc với List, Set, Queue
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    String s = it.next();
}

// ListIterator: chỉ List, nhưng mạnh hơn
ListIterator<String> it = list.listIterator();
while (it.hasNext()) {
    String s = it.next();
    // Có thể đi lùi!
    if (it.hasPrevious()) {
        String prev = it.previous();
    }
}
```

## 🟡 Middle Level

### So sánh

|                 | Iterator               | ListIterator                 |
| --------------- | ---------------------- | ---------------------------- |
| **Collection**  | Tất cả (List, Set, Queue) | Chỉ List                     |
| **Hướng**       | Chỉ tiến              | Tiến và lùi                  |
| **Index**       | Không                  | nextIndex(), previousIndex() |
| **Sửa đổi**     | remove()               | remove(), set(), add()       |
| **Bắt đầu**     | Từ đầu                 | Từ bất kỳ index nào          |

### Con trỏ (Cursor) giữa các phần tử

```
List: [A] [B] [C]
       ↑
    Cursor (giữa A và B)

it.next()     → trả về B, cursor di chuyển sang phải
it.previous() → trả về A, cursor di chuyển sang trái
```

**ListIterator so với `for (int i...)`:** `for (int i...)` cho LinkedList = O(n^2), vì mỗi `get(i)` iterate từ đầu. ListIterator = O(n), vì nó ghi nhớ vị trí hiện tại. Với ArrayList, cả hai cách tiếp cận đều là O(n).

### Tối ưu hóa cho LinkedList

```java
// ❌ O(n²) — mỗi get đều iterate!
for (int i = 0; i < list.size(); i++) {
    list.get(i);  // O(n) cho LinkedList
}

// ✅ O(n) — iterator đã ở vị trí sẵn
ListIterator<String> it = list.listIterator();
while (it.hasNext()) {
    it.next();      // O(1)
    it.add("new");  // O(1) — đã ở node rồi!
}
```

LinkedList.get(i) bắt đầu từ head/tail mỗi lần và bước i lần qua các liên kết. ListIterator đến được node cần thiết một lần và sau đó di chuyển với O(1) — nó lưu một tham chiếu đến Node hiện tại.

## 🔴 Senior Level

### Khi nào KHÔNG dùng ListIterator

1. **Làm việc với Set/Queue** — ListIterator không được hỗ trợ
2. **Chỉ đơn giản đọc các phần tử** — for-each gọn hơn
3. **Cần xử lý song song** — Iterator đơn giản hơn

### Các phương thức sửa đổi

```java
// add(E) — chèn TRƯỚC cursor
it.add("X");
// it.previous() sẽ trả về "X"

// set(E) — thay thế phần tử CUỐI CÙNG được trả về bởi next/previous
it.next();  // → "A"
it.set("B"); // "A" → "B"

// ❌ IllegalStateException nếu next/previous chưa được gọi
it.set("X");  // Lỗi!
```

### forEachRemaining (Java 8+)

```java
Iterator<String> it = list.iterator();
it.forEachRemaining(System.out::println);
// → Các phần tử còn lại
```

### Tối ưu hóa cho LinkedList

```
LinkedList.get(500) → 500 lần duyệt node
ListIterator ở vị trí 500:
  → add/remove/set → O(1)
  → Đã giữ một tham chiếu đến Node!
```

### Best Practices

1. **Iterator** → cho tất cả các collection
2. **ListIterator** → cho List, đặc biệt là LinkedList
3. **Cursor** giữa các phần tử
4. **set/add** phụ thuộc vào next/previous cuối cùng
5. **listIterator(index)** → bắt đầu từ một vị trí
6. **forEachRemaining** → Java 8+ phong cách hàm (functional)

### Tóm tắt cho Senior

- **Iterator** = phổ quát, chỉ tiến
- **ListIterator** = List, hai chiều, sửa đổi
- **Cursor** giữa các phần tử
- **LinkedList** → ListIterator cực kỳ quan trọng cho O(1)
- **set/add** → sau next/previous

## 🎯 Tóm tắt phỏng vấn (Interview Cheat Sheet)

**Cần phải biết:**
- `Iterator` làm việc với tất cả các collection (List, Set, Queue), chỉ tiến về phía trước
- `ListIterator` chỉ cho List, nhưng hỗ trợ: di chuyển lùi, index, `set()`, `add()`
- Cursor của ListIterator nằm GIỮA các phần tử — `next()` trả về phần tử bên phải, `previous()` — bên trái
- Với LinkedList: `for (int i...)` = O(n^2), `ListIterator` = O(n)
- `set()` và `add()` chỉ hoạt động sau khi gọi `next()` hoặc `previous()`
- `listIterator(index)` cho phép bắt đầu iterate từ bất kỳ vị trí nào
- `forEachRemaining()` (Java 8+) — phong cách hàm cho các phần tử còn lại

**Các câu hỏi phụ thường gặp:**
- *Tại sao `for (int i...)` cho LinkedList là O(n^2)?* — Mỗi `get(i)` bước từ đầu/cuối qua các node; n lời gọi × n bước = O(n^2).
- *Khi nào ListIterator.add("X") chèn phần tử?* — Trước cursor; lần `previous()` tiếp theo sẽ trả về "X".
- *Có thể dùng ListIterator với HashSet không?* — Không, Set không hỗ trợ ListIterator — chỉ Iterator thông thường.
- *Điều gì xảy ra nếu bạn gọi set() mà không có next() trước đó?* — `IllegalStateException` — không có "phần tử cuối cùng" để thay thế.

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- "ListIterator làm việc với Set" — không, chỉ với List
- "Iterator có thể di chuyển lùi" — không, chỉ ListIterator có `previous()`
- "`for (int i...)` và ListIterator hiệu quả như nhau cho LinkedList" — không, O(n^2) so với O(n)
- "`set()` thay thế phần tử tiếp theo" — không, nó thay thế phần tử cuối cùng được trả về bởi `next()`/`previous()`
