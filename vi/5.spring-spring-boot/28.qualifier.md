# What is @Qualifier? (@Qualifier là gì?)

## Junior Level

**@Qualifier** chỉ định inject chính xác bean nào.

```java
// Hai bean kiểu PaymentService
@Bean public PaymentService stripe() { ... }
@Bean public PaymentService paypal() { ... }

// Chọn qua @Qualifier:
@Autowired
@Qualifier("stripe")
private PaymentService payment;
```

**Tại sao:**
- Khi có nhiều bean cùng kiểu
- Để chỉ định chính xác cái cần

---

## Middle Level

### Cách hoạt động

```
1. Spring tìm tất cả các bean của kiểu đó
2. Nếu có @Qualifier -> lọc theo tên/annotation
3. @Qualifier > @Primary về ưu tiên. @Qualifier là một chỉ định tường minh một bean cụ thể,
Spring coi nó chính xác hơn. @Primary là một marker "mặc định" toàn cục.
Lựa chọn tường minh luôn được ưu tiên.
```

### Trên các phương thức @Bean

```java
@Configuration
public class Config {

    @Bean
    @Qualifier("fast")
    public RestTemplate fastRestTemplate() { ... }

    @Bean
    @Qualifier("slow")
    public RestTemplate slowRestTemplate() { ... }
}
```

### Custom Qualifier

```java
@Qualifier  // Meta-annotation!
@Retention(RUNTIME)
public @interface FastService { }

@FastService
@Bean
public Service fastService() { ... }

@Autowired
@FastService
private Service service;

// -> Type-safe, không dùng chuỗi!
```

## Senior Level

### Ưu tiên

```
@Qualifier > @Primary > byName > @Priority

-> Nếu có @Qualifier -> @Primary bị bỏ qua!
```

### Với các thuộc tính

```java
@Qualifier
@Retention(RUNTIME)
public @interface Database {
    String value() default "postgres";
    boolean readOnly() default false;
}

// Spring so khớp TẤT CẢ các thuộc tính!
@Database(value = "postgres", readOnly = true)
@Bean
public DataSource readOnlyDb() { ... }
```

### Giới hạn của ObjectProvider

```java
// Chọn qualifier theo lối lập trình là khó
// Giải pháp: Map<String, T>
@Autowired
Map<String, Service> services;

Service service = services.get("fast");
```

### Kinh nghiệm Production

**Tình huống thực tế: lỗi chính tả trong chuỗi**
```
@Qualifier("fastService")  // Quên "s"
-> NoSuchBeanDefinitionException

Giải pháp: các annotation tùy chỉnh
-> Compiler bắt lỗi
```

### Best Practices

1. **Các annotation tùy chỉnh** -> type-safe
2. **@Qualifier > @Primary** -> ưu tiên
3. **Trên các phương thức @Bean** -> cho nhiều bean
4. **Map** -> giải pháp thay thế cho việc chọn động
5. **Tránh** chuỗi -> lỗi chính tả
6. **Trong Spring Boot 3+ (Jakarta EE) annotation này chuyển từ `javax.inject` sang `jakarta.inject`. Chức năng vẫn như cũ.**

### Tóm tắt cho Senior

- **@Qualifier** -> làm rõ lựa chọn
- **@Qualifier > @Primary** -> ưu tiên
- **Các annotation tùy chỉnh** -> type-safe
- **Các thuộc tính** -> tinh chỉnh
- **Map** -> chọn động
- **Tránh** chuỗi -> lỗi chính tả

## Interview Cheat Sheet

**Cần phải biết:**
- @Qualifier chỉ định inject chính xác bean nào khi có nhiều bean cùng kiểu
- Ưu tiên: @Qualifier > @Primary > byName > @Priority
- @Qualifier đặt trên các phương thức @Bean và các điểm inject (@Autowired, constructor)
- Custom qualifier: @Qualifier làm meta-annotation -> an toàn về kiểu, không có chuỗi lỗi chính tả
- Custom qualifier với các thuộc tính: Spring so khớp TẤT CẢ các thuộc tính của annotation qualifier
- Trong Spring Boot 3+ (Jakarta EE) @Qualifier chuyển từ javax.inject sang jakarta.inject
- Map<String, T> — giải pháp thay thế cho việc chọn động mà không cần @Qualifier

**Các câu hỏi phụ thường gặp:**
- *Cái nào quan trọng hơn: @Qualifier hay @Primary?* — @Qualifier luôn được ưu tiên; khi có @Qualifier, @Primary bị bỏ qua.
- *Tại sao custom qualifier tốt hơn chuỗi?* — Compiler kiểm tra kiểu; lỗi chính tả trong chuỗi chỉ bị bắt lúc runtime.
- *Có thể dùng @Qualifier với các thuộc tính không?* — Có, Spring so khớp tất cả các thuộc tính của một annotation custom qualifier.
- *Điều gì xảy ra khi có lỗi chính tả trong chuỗi @Qualifier?* — NoSuchBeanDefinitionException — không tìm thấy bean với tên đó.

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- "@Primary ghi đè @Qualifier" — không, @Qualifier luôn được ưu tiên.
- "@Qualifier tìm bean theo kiểu" — không, @Qualifier lọc theo tên/annotation trong số các bean cùng kiểu.
- "Dùng chuỗi trong @Qualifier là best practice" — không, các annotation tùy chỉnh mới là type-safe.
- "@Qualifier chỉ hoạt động với @Autowired" — không, còn trên @Inject, @Bean, các tham số constructor.
