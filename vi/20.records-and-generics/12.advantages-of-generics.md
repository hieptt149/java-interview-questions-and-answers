# What Are the Advantages of Using Generics? (Những ưu điểm của việc dùng Generics là gì)

## 🟢 Junior Level

**Generics** mang lại ba ưu điểm chính:

1. **Tính an toàn kiểu** — lỗi được bắt tại compile time, không phải runtime
2. **Không cần cast** — code sạch hơn và an toàn hơn
3. **Tái sử dụng code** — một class hoạt động với các kiểu khác nhau

```java
// ❌ Không có generics (trước Java 5)
List list = new ArrayList();
list.add("Hello");
list.add(42);  // trình biên dịch không phàn nàn, nhưng đây là bug!
String s = (String) list.get(1);  // ClassCastException tại runtime!

// ✅ Có generics
List<String> list = new ArrayList<>();
list.add("Hello");
// list.add(42);  // lỗi biên dịch — kiểu được bảo vệ!
String s = list.get(0);  // không cần cast!
```

## 🟡 Middle Level

### Chi Tiết Các Ưu Điểm

**1. Tính an toàn kiểu tại compile time:**
```java
// Lỗi được phát hiện trước khi chạy
List<User> users = new ArrayList<>();
users.add(new User());
// users.add("string");  // lỗi biên dịch — vấn đề được tìm thấy ngay lập tức
```

**2. Loại bỏ cast:**
```java
// Không có generics
Map map = new HashMap();
map.put("key", "value");
String value = (String) map.get("key");  // cần cast

// Có generics
Map<String, String> map = new HashMap<>();
map.put("key", "value");
String value = map.get("key");  // không cần cast
```

**3. Thuật toán generic:**
```java
// Một phương thức cho bất kỳ kiểu nào
public static <T> void swap(List<T> list, int i, int j) {
    T temp = list.get(i);
    list.set(i, list.get(j));
    list.set(j, temp);
}

swap(users, 0, 1);       // T = User
swap(strings, 0, 1);     // T = String
swap(integers, 0, 1);    // T = Integer
```

**4. Chuyên biệt hóa thông qua bound:**
```java
// Chỉ hoạt động với các kiểu Comparable
public static <T extends Comparable<T>> T max(List<T> list) {
    return list.stream().max(Comparable::compareTo).orElse(null);
}

max(List.of(3, 1, 4, 1, 5));  // 5
max(List.of("c", "a", "b"));  // "c"
```

### Các Lỗi Thường Gặp

1. **Bỏ qua cảnh báo:**
```java
// ⚠️ Cảnh báo unchecked cast
List<String> list = (List<String>) someRawList;

// Tốt hơn — tránh raw type
```

2. **Trộn generic và raw:**
```java
List<String> typed = new ArrayList<>();
List raw = typed;  // raw type — tính an toàn kiểu bị mất
raw.add(42);       // trình biên dịch không phàn nàn
```

## 🔴 Senior Level

### Triển Khai Nội Bộ

**Ưu điểm của Type Erasure:**
```
1. Tương thích nhị phân — code Java 5 hoạt động với thư viện Java 1.4
2. Overhead runtime bằng không — không có kiểm tra bổ sung
3. Không có dữ liệu bổ sung trong bộ nhớ
```

**Bridge method:**
```java
public class Node<T extends Comparable<T>> {
    private T data;
    public T getData() { return data; }
}

public class StringNode extends Node<String> {
    @Override
    public String getData() { return super.getData(); }
}

// Sau erasure trình biên dịch tạo một bridge method:
// public Object getData() { return this.getData(); } // gọi String getData()
// Đây là một bridge method — nó giữ tính đa hình sau type erasure.
```

### Đánh Đổi Kiến Trúc

**Generics so với các lựa chọn thay thế:**

| Cách tiếp cận            | Ưu điểm                          | Nhược điểm                   |
| ----------------- | ------------------------------ | ------------------------ |
| **Generics**     | Tính an toàn kiểu, tái sử dụng | Hạn chế của type erasure |
| **Object**        | Đơn giản                       | Cast, lỗi runtime     |
| **Sinh code** | Kiểu hóa đầy đủ               | Nhiều code hơn              |

### Edge Cases

**1. Varargs generic:**
```java
// ⚠️ Cảnh báo heap pollution
@SafeVarargs
public static <T> void printAll(List<T>... lists) {
    for (List<T> list : lists) {
        System.out.println(list);
    }
}
```

**2. Ngoại lệ generic:**
```java
// ❌ Không thể tham số hóa Throwable
public class GenericException<T> extends Exception {}  // lỗi

// ✅ Phương thức generic có thể ném ngoại lệ
public static <T extends Exception> void rethrow(Exception e) throws T {
    throw (T) e;
}
```

### Hiệu Năng

```
Generics:
- Runtime: Overhead bằng không (type erasure)
- Bộ nhớ: Không có dữ liệu bổ sung
- Cast: Cast ngầm định (không đáng kể)

Có generics so với không có:
- Thời gian biên dịch: hơi lâu hơn (kiểm tra kiểu)
- Runtime: giống hệt
- An toàn: cao hơn đáng kể
```

### Kinh Nghiệm Production

**Builder an toàn kiểu:**
```java
public class QueryBuilder<T> {
    private final Class<T> resultType;
    private String sql;
    private final Map<String, Object> params = new HashMap<>();

    public QueryBuilder(Class<T> resultType) {
        this.resultType = resultType;
    }

    public QueryBuilder<T> sql(String sql) {
        this.sql = sql;
        return this;
    }

    public QueryBuilder<T> param(String name, Object value) {
        params.put(name, value);
        return this;
    }

    public List<T> execute() {
        // thực thi an toàn kiểu
        return jdbcTemplate.query(sql, params, resultType);
    }
}

// Sử dụng
List<User> users = new QueryBuilder<>(User.class)
    .sql("SELECT * FROM users WHERE age > :age")
    .param("age", 18)
    .execute();
```

### Best Practices

```java
// ✅ Phương thức generic để tái sử dụng
public static <T> Optional<T> first(List<T> list, Predicate<T> predicate) {
    return list.stream().filter(predicate).findFirst();
}

// ✅ Bounded type
public static <T extends Comparable<T>> void sort(List<T> list) { }

// ✅ Wildcard cho tính linh hoạt (PECS)
public void process(List<? extends Number> numbers) { }

// ❌ Raw type
// ❌ Unchecked cast không cần thiết
// ❌ Bỏ qua cảnh báo trình biên dịch
```

## 🎯 Interview Cheat Sheet

**Cần phải biết:**
- Tính an toàn kiểu tại compile time — lỗi kiểu được bắt trước khi chương trình chạy
- Loại bỏ cast — không cần cast rõ ràng khi lấy từ collection
- Tái sử dụng code — một class generic hoạt động với bất kỳ kiểu nào
- Type erasure = overhead runtime bằng không, tương thích nhị phân với Java 1.4
- Bridge method giữ tính đa hình sau type erasure
- Thuật toán generic: `swap`, `max`, `filter` hoạt động với bất kỳ kiểu nào

**Các câu hỏi phụ thường gặp:**
- **Ưu điểm chính của generics là gì?** — Tính an toàn kiểu tại compile time + không cần cast
- **Có overhead runtime không?** — Không, type erasure = overhead bằng không tại runtime
- **Bridge method là gì?** — Phương thức tổng hợp để giữ tính đa hình sau erasure
- **Có thể có ngoại lệ generic không?** — Không, `class GenericException<T> extends Exception` — lỗi

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- ❌ "Generics làm chậm chương trình" — Overhead runtime bằng không
- ❌ "Raw type ổn trong code mới" — Raw type tắt tất cả việc kiểm tra kiểu
- ❌ "Generics tạo thêm object" — Không có cấp phát bổ sung
- ❌ "Varargs generic luôn an toàn" — Heap pollution có thể xảy ra, cần @SafeVarargs
