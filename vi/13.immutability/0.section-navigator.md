## Tham khảo nhanh: Cần biết gì ở mỗi cấp độ

### Basic
- Immutable = trạng thái không thay đổi sau khi tạo
- Ưu điểm: thread-safe, cacheable, dễ dự đoán
- final cho class, trường, method — ba ý nghĩa khác nhau
- String bất biến — bảo mật, String Pool, hashing

### Intermediate
- Defensive copy: sao chép các trường mutable trong constructor và getter
- `List.copyOf()` vs `Collections.unmodifiableList()` — bản sao độc lập vs wrapper sống
- Shallow copy = sao chép container, deep copy = sao chép đệ quy toàn bộ đồ thị
- Record = value class bất biến với boilerplate tối thiểu
- Builder pattern cho các object có 4+ trường

### Advanced
- Reflection trên các trường final bị chặn (Java 16+, JEP 396)
- Sealed class (Java 17) như một giải pháp thay thế cho final với các hệ thống phân cấp bất biến
- Cấu trúc dữ liệu persistent: structural sharing, sửa đổi O(log n)
- Mutable key trong HashMap = không thể truy cập logic (không phải rò rỉ!)
- Immutable object = mở rộng tuyến tính trên các workload đọc nặng
- String Pool gắn liền với tính bất biến: một object → nhiều tham chiếu an toàn
