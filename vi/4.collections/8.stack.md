# What is Stack? (Stack là gì?)

## 🟢 Junior Level

**Stack** — cấu trúc dữ liệu tuân theo nguyên tắc **LIFO** (Last In, First Out — vào sau, ra trước).

**Ví dụ minh họa đơn giản:** Chồng đĩa. Bạn đặt lên trên cùng, bạn lấy từ trên cùng.

**Tại sao cần LIFO:** phần tử được thêm vào cuối cùng là phần tử liên quan nhất. Ví dụ: hoàn tác thao tác (Ctrl+Z), các lời gọi phương thức (call stack), phân tích dấu ngoặc, DFS (duyệt đồ thị theo chiều sâu).

**Các thao tác:**
- `push(e)` — đặt lên trên cùng
- `pop()` — lấy từ trên cùng
- `peek()` — xem phần tử trên cùng

```java
// ❌ Đừng dùng java.util.Stack
Stack<String> stack = new Stack<>();  // Legacy!

// ✅ Hãy dùng ArrayDeque
Deque<String> stack = new ArrayDeque<>();
stack.push("A");
stack.push("B");
stack.pop();  // → "B" (vào sau, ra trước)
```

## 🟡 Middle Level

### Tại sao java.util.Stack tệ

```java
// Stack extends Vector!
public class Stack<E> extends Vector<E> { ... }

// Các vấn đề:
// 1. Tất cả các phương thức đều synchronized → chậm
// 2. Có thể gọi get(0), add(0, e) → phá vỡ LIFO
// 3. Kế thừa từ Vector = legacy
```

### Giải pháp thay thế đúng đắn: ArrayDeque

```java
// ✅ ArrayDeque — nhanh, không đồng bộ hóa
Deque<String> stack = new ArrayDeque<>();

stack.push("A");      // Push
stack.push("B");
String top = stack.peek();  // "B" — đã xem
String popped = stack.pop(); // "B" — đã lấy ra

// Các exception:
// pop() trên stack rỗng → NoSuchElementException
// peek() trên stack rỗng → null
```

### So sánh

|                     | Stack                                                                                                                              | ArrayDeque    | LinkedList    |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------- | ------------- |
| **push/pop**        | O(1)                                                                                                                               | O(1)          | O(1)          |
| **Đồng bộ hóa**     | Có                                                                                                                                | Không         | Không         |
| **Bộ nhớ**          | Trung bình                                                                                                                         | Thấp          | Cao           |
| **Có thể get(index)** | ❌ Có (tệ! get(index) cho phép truy cập các phần tử không qua đỉnh, phá vỡ ngữ nghĩa LIFO. Client có thể vô tình dùng stack như một list) | ❌ Không       | ❌ Không       |

### Các trường hợp sử dụng (Use Cases)

```java
// 1. Undo/Redo
Deque<Action> undo = new ArrayDeque<>();
undo.push(action);
Action last = undo.pop();

// 2. Kiểm tra dấu ngoặc (bracket validation)
Deque<Character> stack = new ArrayDeque<>();
for (char c : expression.toCharArray()) {
    if (c == '(') stack.push(c);
    if (c == ')') stack.pop();
}

// 3. DFS (duyệt theo chiều sâu)
Deque<Node> stack = new ArrayDeque<>();
stack.push(root);
```

## 🔴 Senior Level

### Khi nào KHÔNG dùng stack

1. **Nếu cần truy cập ngẫu nhiên** — hãy dùng List
2. **Nếu cần xử lý FIFO** — hãy dùng Queue/ArrayDeque
3. **Nếu là BFS (breadth-first search)** — queue, không phải stack

### Vi phạm LSP

LSP (Liskov Substitution Principle) — lớp con phải có thể thay thế được cho lớp cơ sở. Stack extends Vector vi phạm điều này: Vector cho phép `get(index)`, điều này phá vỡ ngữ nghĩa LIFO.

```
Stack extends Vector
  → Stack "là một" list
  → Nhưng có thể chèn vào giữa: stack.add(0, x)
  → Phá vỡ tính đóng gói (encapsulation) của stack!

ArrayDeque implements Deque
  → Chỉ truy cập thông qua push/pop/peek
  → Không thể phá vỡ ngữ nghĩa LIFO
```

### Các hợp đồng Exception (Exception Contracts)

```java
// java.util.Stack:
stack.pop();        // → EmptyStackException

// ArrayDeque:
deque.pop();        // → NoSuchElementException

// Khi refactoring: hãy catch đúng kiểu!
```

### Concurrency

```java
// Nếu cần stack thread-safe:

// ❌ Stack (chậm, khóa thô — coarse-grained lock)
Stack<String> stack = new Stack<>();

// ✅ ConcurrentLinkedDeque (lock-free)
Deque<String> stack = new ConcurrentLinkedDeque<>();

// ✅ Deque được synchronized
Deque<String> stack = Collections.synchronizedDeque(new ArrayDeque<>());
```

### Kinh nghiệm Production

**Trường hợp thực tế: Stack → ArrayDeque**
- Bộ phân tích biểu thức (expression parser): Stack
- Lock contention: 60% thời gian
- Giải pháp: ArrayDeque
- Kết quả: +250% throughput

(Dựa trên các benchmark nội bộ. Kết quả của bạn sẽ phụ thuộc vào tải, JVM và CPU.)

### Best Practices

1. **KHÔNG dùng** `java.util.Stack`
2. **ArrayDeque** — cho stack trong 99% các trường hợp
3. **ConcurrentLinkedDeque** — cho thread-safe
4. **Interface Deque** trong các chữ ký, không phải cài đặt
5. **push/pop/peek** — các phương thức chuẩn
6. **Kế thừa từ Vector** = sai lầm về kiến trúc

### Tóm tắt cho Senior

- **Stack** = legacy, extends Vector, synchronized
- **ArrayDeque** = giải pháp thay thế đúng đắn (nhanh hơn, ít bộ nhớ hơn)
- **Vi phạm LSP** = Stack có thể được dùng như một list
- **Lock-free** = ConcurrentLinkedDeque cho concurrency
- **Các exception** = EmptyStackException so với NoSuchElementException
- **KHÔNG BAO GIỜ** dùng `java.util.Stack` trong code mới

## 🎯 Tóm tắt phỏng vấn (Interview Cheat Sheet)

**Cần phải biết:**
- Stack = LIFO (Last In, First Out), push/pop/peek — các thao tác chính
- java.util.Stack là legacy — extends Vector, tất cả các phương thức đều synchronized, vi phạm LSP
- ArrayDeque — giải pháp thay thế đúng đắn cho stack trong 99% các trường hợp (nhanh hơn, ít bộ nhớ hơn, không đồng bộ hóa)
- Vi phạm LSP: Stack extends Vector → có thể gọi get(index), phá vỡ ngữ nghĩa LIFO
- Các hợp đồng exception: Stack.pop() → EmptyStackException, ArrayDeque.pop() → NoSuchElementException
- Use Cases: Undo/Redo, call stack, phân tích dấu ngoặc, DFS (duyệt theo chiều sâu)
- Thread-safe: ConcurrentLinkedDeque (lock-free) hoặc Collections.synchronizedDeque
- Trường hợp thực tế: thay Stack → ArrayDeque cho +250% throughput trong parser

**Các câu hỏi phụ thường gặp:**
- Tại sao java.util.Stack tệ? — Kế thừa từ Vector: synchronized (chậm) + có thể phá vỡ LIFO qua get(index)
- ArrayDeque tốt hơn Stack như thế nào? — Không đồng bộ hóa, ít bộ nhớ hơn, không thể phá vỡ ngữ nghĩa LIFO
- Làm sao tạo stack thread-safe? — ConcurrentLinkedDeque (lock-free) hoặc Collections.synchronizedDeque(new ArrayDeque<>())
- Khi nào KHÔNG dùng stack? — Nếu cần truy cập ngẫu nhiên (List) hoặc xử lý FIFO (Queue)

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- ❌ "java.util.Stack — lựa chọn ổn" — nó là legacy, hãy dùng ArrayDeque
- ❌ "Stack đóng gói LIFO hoàn toàn" — không, có thể gọi get(index) qua việc kế thừa Vector
- ❌ "Synchronized = stack thread-safe" — khóa thô giết chết tính song song, hãy dùng lock-free
- ❌ "Stack và Queue có thể thay thế cho nhau" — LIFO so với FIFO, ngữ nghĩa khác nhau
