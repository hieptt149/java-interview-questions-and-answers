## 🔗 Các mối liên hệ chính giữa các chủ đề

### Chủ đề: List

```
Q3 (ArrayList vs LinkedList) → Q4 (Khi nào dùng cái nào) → Q5-Q6 (Big O)
                                                ↓
                                       Q7 (Vector) → Q8 (Stack) → Q9 (Queue) → Q10 (Deque)
```

**Các mối liên hệ chính:**
- Q3 ↔ Q5-Q6: Big O giải thích tại sao ArrayList nhanh hơn LinkedList trong thực tế
- Q4 ↔ Q28: removeIf() giải quyết vấn đề xóa-trong-vòng-lặp
- Q7 ↔ Q18: Vector → ConcurrentHashMap (sự tiến hóa của thread-safety)
- Q9-Q10 ↔ Q18: BlockingQueue, ConcurrentLinkedQueue như các giải pháp thay thế

### Chủ đề: Set

```
Q11 (HashSet vs LinkedHashSet vs TreeSet) → Q12 (Nội tại HashSet) → Q13 (TreeSet)
```

**Các mối liên hệ chính:**
- Q11 ↔ Q14: Set dùng Map bên trong (HashSet = HashMap<E, Object>)
- Q12 ↔ Q15: Nội tại HashSet = nội tại HashMap
- Q13 ↔ Q16: TreeSet = TreeMap.keySet(), khi nào cần TreeMap

### Chủ đề: Map

```
Q14 (Tổng quan Map) → Q15 (HashMap vs LinkedHashMap vs TreeMap) → Q16 (TreeMap)
     ↓                          ↓                          ↓
Q17 (WeakHashMap)      Q12 (Nội tại HashSet)      Q18-19 (ConcurrentHashMap)
                                ↓
                       Q20 (CopyOnWriteArrayList)
```

**Các mối liên hệ chính:**
- Q14 ↔ Q1: Map về mặt kỹ thuật KHÔNG phải là một Collection, nhưng là một phần của Framework
- Q15 ↔ Q12: Nội tại HashMap = nội tại HashSet
- Q17 ↔ Q3 (Memory and GC): WeakReference, GC, SoftReference
- Q18-19 ↔ Q21: CHM vs synchronizedList — các cách tiếp cận khác nhau về thread-safety
- Q18 ↔ Q20: CHM cho workload hỗn hợp, COWAL cho read-heavy

### Chủ đề: Thread-Safety

```
Q7 (Vector) → Q21 (synchronized collections) → Q22 (Cách lấy được)
     ↓                          ↓                          ↓
Q18 (CHM) ←────────────── Q19 (Thread-safety của CHM)  Q20 (CopyOnWriteArrayList)
```

**Các mối liên hệ chính:**
- Q7 ↔ Q21: Vector — cách tiếp cận legacy, synchronizedList — hiện đại
- Q18 ↔ Q20: CHM = các khóa chi tiết (granular), COWAL = snapshot
- Q21 ↔ Q26: synchronizedList = fail-fast, CHM = weakly consistent

### Chủ đề: Iterator và xóa

```
Q25 (Iterator vs ListIterator) → Q26 (fail-fast vs fail-safe)
     ↓                                  ↓
Q27 (CME) ←──────────────────────── Q28 (Xóa đúng cách)
     ↑

```

**Các mối liên hệ chính:**
- Q25 ↔ Q28: Iterator.remove() — cách xóa đúng đắn
- Q26 ↔ Q27: fail-fast ném CME, fail-safe — thì không
- Q23-24 ↔ Q27: unmodifiableList không bảo vệ chống CME thông qua view

## 🎓 Bảng tóm tắt: Cần biết gì cho mỗi cấp độ

### 🟢 Junior
- Phân cấp: Collection → List/Set/Queue, Map — song song
- ArrayList vs LinkedList: ArrayList cho hầu hết các trường hợp
- HashSet = tính duy nhất, TreeSet = sắp xếp
- HashMap = key-value, TreeMap = được sắp xếp theo key
- Vector/Stack — legacy, hãy dùng ArrayList/ArrayDeque
- Iterator để iterate, không thể xóa trong for-each
- unmodifiableList = lớp bọc phòng thủ, không phải bất biến sâu

### 🟡 Middle
- Big O: ArrayList add = O(1) phân bổ, get = O(1); LinkedList get = O(n)
- Cache locality: ArrayList > LinkedList 10-100 lần khi iterate
- HashSet = HashMap bên trong, treeification khi có > 8 phần tử cho mỗi bucket
- ConcurrentHashMap: CAS + volatile + synchronized, KHÔNG chặn các lần đọc
- CopyOnWriteArrayList: snapshot, fail-safe, sao chép O(n) khi ghi
- fail-fast = modCount, CME = bộ phát hiện bug (không phải đồng bộ hóa!)
- removeIf() = O(n) cho ArrayList, Iterator.remove() = O(n²)
- Comparable = thứ tự tự nhiên, Comparator = sắp xếp bên ngoài

### 🔴 Senior
- System.arraycopy: JVM intrinsic, SIMD, branch prediction
- Cache miss của LinkedList: mỗi node — một đối tượng riêng trên heap
- CHM: CounterCells (LongAdder), ForwardingNode, ReservationNode
- WeakHashMap: ReferenceQueue, expungeStaleEntries, Minor GC
- size() của ConcurrentHashMap: không phải một khóa, mà là một bộ đếm thông qua CAS
- Timsort: sắp xếp ổn định, tính bắc cầu, tràn số
- Spliterator: các đặc tính (SIZED, DISTINCT, SORTED) cho tối ưu hóa Stream
- Java 21: SequencedCollection/SequencedSet/SequencedMap
