
**Các mối liên hệ chính:**

**Các mối liên hệ chính:**

## Bảng tóm tắt: Cần biết gì cho mỗi cấp độ

### Junior
- REST = tập hợp các ràng buộc (Stateless, Uniform Interface, Resources)
- GET = đọc, POST = tạo, PUT = thay thế, PATCH = cập nhật một phần, DELETE = xóa
- 200 = OK, 201 = Created, 400 = Bad Request, 401 = Unauthenticated, 403 = Forbidden, 404 = Not Found, 500 = Server Error
- Stateless = server không nhớ client giữa các request

### Middle
- Idempotency: lời gọi lặp lại = kết quả giống nhau. GET/PUT/DELETE là idempotent, POST không
- PUT thay thế tài nguyên hoàn toàn, PATCH cập nhật một phần
- 401 = bạn là ai? (không có token), 403 = không được phép (không có quyền)
- Richardson Maturity Model: Level 0 (RPC) -> Level 1 (Resources) -> Level 2 (HTTP methods) -> Level 3 (HATEOAS)
- Content-Type = định dạng request body, Accept = định dạng response ưa thích

### Senior
- HATEOAS affordances: server gợi ý các hành động có sẵn cho client thông qua các link
- Idempotency-Key: UUID trong header để retry an toàn các request POST
- Media Type Versioning gần với tinh thần REST hơn, nhưng URL versioning thực tế hơn
- Expand & Contract: chiến lược migration không có downtime
- Protobuf nhanh hơn JSON 3-10 lần, nhưng khó debug hơn
- Negative Caching: cache 404/403 để bảo vệ chống brute-force
