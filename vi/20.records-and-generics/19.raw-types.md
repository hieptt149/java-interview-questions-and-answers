# What Are Raw Types and Why Should You Avoid Them? (Raw type là gì và tại sao nên tránh chúng)

## 🟢 Junior Level

**Raw type** — dùng một class generic **mà không chỉ định kiểu**.

```java
// ✅ Parameterized type
List<String> list = new ArrayList<>();
list.add("Hello");
String s = list.get(0);  // không cần cast

// ❌ Raw type — không có kiểu
List list = new ArrayList();  // raw type!
list.add("Hello");
list.add(42);  // trình biên dịch không phàn nàn, nhưng đây là bug!
String s = (String) list.get(0);  // cần cast
String s2 = (String) list.get(1); // ClassCastException!
```

**Tại sao nên tránh:**
1. ❌ Không có kiểm tra kiểu tại compile-time
2. ❌ Cần cast
3. ❌ Nguy cơ `ClassCastException` tại runtime

## 🟡 Middle Level

### Raw Type Là Gì

Raw type là một class generic **không có type argument**:

```java
// Class generic
public class Box<T> {
    private T value;
    public void set(T value) { this.value = value; }
    public T get() { return value; }
}

// Sử dụng parameterized
Box<String> stringBox = new Box<>();  // ✅

// Raw type
Box rawBox = new Box();  // ❌ cảnh báo: raw type
```

**Điều gì xảy ra:**
```java
Box rawBox = new Box();
rawBox.set("Hello");
rawBox.set(42);  // trình biên dịch không phàn nàn!

// Sau type erasure:
Box rawBox = new Box();
rawBox.set("Hello");
rawBox.set(Integer.valueOf(42));  // mọi thứ đều được lưu

// Khi đọc — ClassCastException
String s = (String) rawBox.get();  // OK
Integer i = (Integer) rawBox.get();  // OK
String s2 = (String) rawBox.get();  // ClassCastException!
```

### Các Lỗi Thường Gặp

1. **Tương thích code legacy:**
```java
// Code trước Java 5
List list = new ArrayList();
list.add("Hello");

// Code mới
List<String> strings = list;  // cảnh báo: unchecked conversion
```

2. **Trộn raw và parameterized:**
```java
Map<String, List<String>> map = new HashMap<>();
Map rawMap = map;  // raw type — mất tính an toàn kiểu
rawMap.put("key", 42);  // trình biên dịch không phàn nàn

// Sau đó — ClassCastException
List<String> list = map.get("key");  // ClassCastException!
```

### Sử Dụng Thực Tế

**Cách dùng raw type duy nhất có thể chấp nhận — getClass():**
```java
// getClass() trả về Class<? extends |X|>, không phải raw type.
// Gán cho Class — unchecked conversion, không phải thiết kế có chủ đích.
Class<?> clazz = "Hello".getClass();
Class rawClass = "Hello".getClass();  // cũng OK, nhưng là unchecked conversion

// Nhưng wildcard tốt hơn
Class<?> better = "Hello".getClass();
```

### Khi Nào Raw Type Có Thể Chấp Nhận

- Tương thích với thư viện trước Java 5
- Một số kịch bản reflection nhất định
- Class literal: `Class.class` (mặc dù `Class<?>` tốt hơn)

## 🔴 Senior Level

### Triển Khai Nội Bộ

**Type erasure với raw type:**
```java
// Raw type — tất cả kiểm tra kiểu bị tắt
List<String> typed = new ArrayList<>();
List raw = typed;

raw.add(42);  // trình biên dịch cho phép!
raw.add(true); // trình biên dịch cho phép!

// Nhưng type erasure lưu dữ liệu dưới dạng Object
// raw = typed sau erasure — cùng một object
```

**Cảnh báo unchecked:**
```java
// Trình biên dịch đưa ra cảnh báo:
// warning: [unchecked] unchecked call to add(E) as a member of raw type List
raw.add(42);

// warning: [unchecked] unchecked conversion
List<String> list = raw;

// warning: [rawtypes] raw type
Box box = new Box();
```

### Đánh Đổi Kiến Trúc

**Raw type so với parameterized:**

| Raw type               | Parameterized         |
| ----------------------- | --------------------- |
| Không kiểm tra kiểu        | Kiểm tra compile-time    |
| Nguy cơ ClassCastException | An toàn kiểu          |
| Tương thích legacy    | Code hiện đại           |
| Không cast khi truy cập       | Không cần cast        |

### Edge Cases

**1. Raw type trong kế thừa:**
```java
public class Node<T> {
    private T data;
    public T getData() { return data; }
}

public class RawNode extends Node {  // raw type!
    @Override
    public Object getData() { return super.getData(); }
}

// Sau erasure — bridge method hoạt động đúng
// Nhưng tính an toàn kiểu bị mất
```

**2. Raw type và phương thức generic:**
```java
public class Util {
    public static <T> T identity(T t) { return t; }
}

// Gọi qua raw type
Util u = new Util();  // raw type
Object result = u.identity("Hello");  // T được suy ra là Object

// Đúng
Object result2 = Util.identity("Hello");  // T = String
```

**3. Raw type trong mảng:**
```java
// Mảng của class generic — raw type
Box<String>[] boxes = new Box[10];  // cảnh báo: raw type

// Tốt hơn
List<Box<String>> boxes = new ArrayList<>();
```

### Hiệu Năng

```
Raw type so với parameterized:
- Runtime: giống nhau (type erasure)
- Compile time: raw type nhanh hơn (không kiểm tra)
- An toàn: parameterized an toàn hơn đáng kể

Hiệu năng giống nhau, nhưng raw type rủi ro hơn
```

### Kinh Nghiệm Production

**Di chuyển legacy:**
```java
// Trước Java 5
public class OldDao {
    public List findAll() {
        return jdbcTemplate.query("SELECT * FROM users", ...);
    }
}

// Sau khi di chuyển
public class NewDao {
    public List<User> findAll() {
        return jdbcTemplate.query("SELECT * FROM users", ...);
    }
}

// Giai đoạn chuyển tiếp — cảnh báo raw type
List users = oldDao.findAll();  // raw type
List<User> typedUsers = newDao.findAll();  // parameterized
```

**@SuppressWarnings("rawtypes"):**
```java
// Chỉ khi không thể tránh khỏi
@SuppressWarnings("rawtypes")
public void legacyInterop() {
    List rawList = legacyMethod();
    // ...
}

// ❌ Đừng ẩn cảnh báo mà không có lý do
// ✅ Sửa nguyên nhân gốc rễ
```

### Best Practices

```java
// ✅ Luôn dùng type argument
List<String> list = new ArrayList<>();
Map<String, Integer> map = new HashMap<>();

// ✅ Diamond operator (Java 7+)
List<String> list = new ArrayList<>();  // không phải new ArrayList<String>()

// ✅ Wildcard khi kiểu không xác định
public void process(List<?> list) { }

// ⚠️ Raw type chỉ cho code legacy
// ⚠️ Ẩn cảnh báo chỉ khi không thể tránh khỏi

// ❌ Raw type trong code mới
// ❌ Trộn raw và parameterized
// ❌ Bỏ qua cảnh báo unchecked
```

## 🎯 Interview Cheat Sheet

**Cần phải biết:**
- Raw type — dùng một class generic không có type argument: `List list = new ArrayList()`
- Raw type tắt việc kiểm tra kiểu tại compile-time — nguy cơ ClassCastException tại runtime
- Trộn raw và parameterized làm lây lan cảnh báo unchecked cho toàn bộ chuỗi
- Raw type duy nhất có thể chấp nhận — code legacy và một số kịch bản reflection
- Sau type erasure, raw và parameterized — cùng một bytecode
- `@SuppressWarnings("rawtypes")` — chỉ khi không thể tránh khỏi, không phải để ẩn mà không có lý do

**Các câu hỏi phụ thường gặp:**
- **Khi nào raw type có thể chấp nhận?** — Thư viện legacy trước Java 5, một số kịch bản reflection
- **Điều gì xảy ra khi trộn raw và parameterized?** — Cảnh báo unchecked, mất tính an toàn kiểu
- **Raw type vs wildcard <?>?** — Raw tắt tất cả kiểm tra, wildcard giữ lại kiểm tra
- **Có thể tạo một mảng của class generic không?** — Có, nhưng nó sẽ là raw type: `new Box[10]`

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- ❌ "Raw type nhanh hơn parameterized" — Hiệu năng runtime giống nhau
- ❌ "Raw type là thực hành bình thường trong code mới" — Luôn dùng type argument
- ❌ "Raw type giống với <?>" — Raw tắt kiểm tra, wildcard giữ lại chúng
- ❌ "SuppressWarnings giải quyết vấn đề" — Cảnh báo vẫn còn, bạn cần sửa nguyên nhân gốc rễ
