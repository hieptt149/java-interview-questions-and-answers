# What Are the Main Differences Between Record and Regular Class? (Sự khác biệt chính giữa Record và class thông thường là gì)

## 🟢 Junior Level

**Record** là một loại class đặc biệt trong Java được thiết kế để lưu trữ dữ liệu. Sự khác biệt chính: Record được tạo ra để trở thành **container dữ liệu đơn giản**, trong khi class thông thường là công cụ đa năng.

**Các khác biệt chính:**

| Record                              | Class thông thường           |
| ----------------------------------- | ----------------------- |
| Tất cả trường `private final`            | Trường bất kỳ              |
| Không thể thay đổi trường sau khi tạo | Có thể thay đổi trường       |
| Kế thừa từ `java.lang.Record`   | Kế thừa từ `Object` |
// java.lang.Record — một class đặc biệt không thể dùng trực tiếp qua extends.
| `implicit final` — không thể mở rộng | Có thể kế thừa từ |
| Tự động sinh `equals`, `hashCode`, `toString` | Phải viết thủ công hoặc qua IDE |

**Ví dụ:**
```java
// Record — một dòng
public record Point(int x, int y) {}

// Class thông thường — 30+ dòng
public class Point {
    private final int x;
    private final int y;

    public Point(int x, int y) {
        this.x = x;
        this.y = y;
    }

    public int x() { return x; }
    public int y() { return y; }

    // cộng thêm equals, hashCode, toString...
}
```

## 🟡 Middle Level

### Cách Hoạt Động

Record là một **dạng class bị hạn chế** trong đó trình biên dịch lo liệu boilerplate:

**1. Constructor:**
```java
// Record — canonical constructor được tự động sinh
public record User(String name, int age) {}

// Có thể thêm constructor riêng (phải gọi canonical)
public record User(String name, int age) {
    public User(String name) {
        this(name, 0);  // ủy quyền
    }
}
```

**2. Getter:**
```java
// Record — không có tiền tố get!
User user = new User("John", 25);
user.name();  // ✅ KHÔNG PHẢI user.getName()
user.age();   // ✅ KHÔNG PHẢI user.getAge()
```

**3. Kế Thừa:**
```java
// ❌ Record không thể được mở rộng
public class Bad extends Point {}  // lỗi biên dịch

// ❌ Record không thể extends bất cứ thứ gì (trừ java.lang.Record)
public record Bad extends Object {}  // lỗi biên dịch

// ✅ Record có thể triển khai interface
public record User(String name) implements Serializable {}
```

### Ứng Dụng Thực Tế

**Khi nào nên dùng Record:**
- DTO cho REST API
- Key trong HashMap/HashSet
- Trả về nhiều giá trị từ một phương thức
- Value object trong DDD

**Khi nào nên dùng class thông thường:**
- Cần trạng thái mutable
- Cần phương thức/trường bổ sung
- Cần kế thừa
- Cần builder pattern với trường mutable

### Các Lỗi Thường Gặp

1. **Cố gắng tạo trường mutable:**
```java
public record BadRecord() {
    // ❌ Trường không static — lỗi biên dịch
    public int mutableField = 0;
}

// ✅ Chỉ static
public record GoodRecord() {
    public static int counter = 0;
}
```

2. **Mong đợi phương thức get/set:**
```java
public record User(String name) {}
User u = new User("John");

// ❌ u.getName() — không có phương thức như vậy!
// ✅ u.name() — lời gọi đúng
```

## 🔴 Senior Level

### Triển Khai Nội Bộ

**Cấu trúc class file:**
```
// Record — đây là một class final với cờ ACC_RECORD
ClassFile {
    access_flags: ACC_FINAL | ACC_RECORD
    super_class: java/lang/Record
    fields: tất cả private final
    methods: canonical constructor + accessor + equals/hashCode/toString
}
```

**Khác biệt ở tầng JVM:**
- Record có một thuộc tính `RecordComponents` đặc biệt trong constant pool
- JVM biết về các thành phần canonical (tên, kiểu, annotation)
- Reflection API: `Class.getRecordComponents()` trả về `RecordComponent[]`

### Đánh Đổi Kiến Trúc

**Record:**
- ✅ Boilerplate tối thiểu
- ✅ Đảm bảo tính bất biến
- ✅ Tối ưu hóa cho value type (Project Valhalla)
- ❌ Không linh hoạt
- ❌ Không thể dùng với JPA entity (cần constructor không tham số)

**Class thông thường:**
- ✅ Kiểm soát toàn diện
- ✅ Tương thích JPA
- ✅ Builder, trạng thái mutable
- ❌ Nhiều code hơn
- ❌ Bảo trì thủ công equals/hashCode

### Edge Cases

**1. Compact constructor cho validation:**
```java
public record Email(String value) {
    public Email {
        if (!value.contains("@")) {
            throw new IllegalArgumentException("Invalid email");
        }
    }
}
```

**2. Annotation trên các thành phần:**
```java
public record User(
    @JsonProperty("user_name") String name,
    @Min(18) int age
) {}
// Annotation được áp dụng cho trường, tham số constructor VÀ accessor
```

**3. Serialization:**
```java
// Record dùng một cơ chế deserialization đặc biệt
// thông qua canonical constructor (JEP 445, Java 21)
// thay vì readObject/writeObject
```

### Hiệu Năng

```
Thao tác          | Record | Class thông thường (trường final)
-------------------|--------|---------------------------
Tạo object    | 8 ns   | 8 ns
equals()           | 15 ns  | 15 ns (triển khai thủ công)
hashCode()         | 12 ns  | 12 ns

Khác biệt tối thiểu — Record không thua kém
// Giá trị xấp xỉ. Phụ thuộc JVM/phần cứng.
```

### Kinh Nghiệm Production

```java
// DTO trong Spring Boot 3.x — Record trở thành chuẩn
public record CreateUserRequest(
    @NotBlank String name,
    @Email String email,
    @Min(18) int age
) {}

// JPA entity — chưa thể dùng Record
// (cần trạng thái mutable, constructor không tham số, lazy loading proxy)
@Entity
public class User {  // class thông thường
    @Id private Long id;
    private String name;
}
```

### Best Practices

```java
// ✅ Record cho DTO bất biến
public record OrderDto(String id, Instant createdAt, BigDecimal amount) {}

// ✅ Record cho value object
public record Money(BigDecimal amount, Currency currency) {
    public Money {
        Objects.requireNonNull(amount);
        Objects.requireNonNull(currency);
    }
}

// ❌ Record cho JPA entity
// ❌ Record cho collection mutable không được bảo vệ
public record BadRecord(int[] values) {}  // mảng là mutable!
```

## 🎯 Interview Cheat Sheet

**Cần phải biết:**
- Record là một loại class bị hạn chế: chỉ trường final, không thể kế thừa, không thể extends
- Record kế thừa từ `java.lang.Record`, class thông thường — từ `Object`
- Tự động sinh `equals`, `hashCode`, `toString` — Record so với code thủ công trong class thông thường
- Record bất biến theo thiết kế; class thông thường có thể mutable hoặc immutable
- Record không thể dùng với JPA (cần constructor không tham số, trạng thái mutable)
- Getter của Record không có `get`: `user.name()` thay vì `user.getName()`

**Các câu hỏi phụ thường gặp:**
- **Khi nào chọn Record thay vì class thông thường?** — Record cho DTO/value object bất biến, class thông thường cho JPA, trạng thái mutable, builder
- **Có thể thêm phương thức bổ sung vào Record không?** — Có, bất kỳ phương thức static và instance nào, nhưng không phải trường instance
- **Record có nhanh hơn class thông thường không?** — Không, hiệu năng giống hệt, khác biệt < 5%
- **Có thể override equals/hashCode trong Record không?** — Có, nhưng hiếm khi cần

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- ❌ "Record là subclass của class thông thường" — Record kế thừa từ `java.lang.Record`, một class đặc biệt
- ❌ "Record hỗ trợ kế thừa" — Record là implicit final
- ❌ "Record dùng get/set" — accessor không có get: `name()` không phải `getName()`
- ❌ "Record phù hợp cho JPA" — JPA yêu cầu constructor không tham số và trường mutable
