# What is a Starter in Spring Boot? (Starter trong Spring Boot là gì?)

## Junior Level

**Starter** là một bộ dependency dựng sẵn cho một chức năng cụ thể.

**Không có Starter:**
```xml
<!-- Cần thêm 5+ dependency thủ công -->
<dependency><groupId>org.springframework</groupId>...</dependency>
<dependency><groupId>org.hibernate</groupId>...</dependency>
...
```

**Có Starter:**
```xml
<!-- Một dependency - mọi thứ hoạt động! -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>
```

**Các starter phổ biến:**
- `spring-boot-starter-web` -> REST API
- `spring-boot-starter-data-jpa` -> Database
- `spring-boot-starter-test` -> Testing

## Middle Level

### Kiến trúc của Starter

```
mylib-spring-boot-starter
  -> mylib-autoconfigure (cấu hình)
    -> @ConditionalOnClass(...)
    -> các phương thức @Bean
  -> mylib (thư viện chính)
```

### Quy ước đặt tên

```
spring-boot-starter-*     -> Starter chính thức
*-spring-boot-starter     -> Starter bên thứ ba
```

### BOM (Bill of Materials)

```xml
<!-- Quản lý version của tất cả các dependency -->
<parent>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-dependencies</artifactId>
</parent>

-> Không "Jar Hell" -> tất cả các version đều tương thích
```

> spring-boot-dependencies là một parent POM với `<dependencyManagement>` cố định version của hàng trăm thư viện. Bạn kế thừa nó qua `<parent>` hoặc import nó vào `<dependencyManagement>` của mình.

### Tùy biến

```yaml
# Starter cung cấp các thiết lập mặc định
# Bạn có thể ghi đè qua application.yaml
mylib:
  enabled: true
  timeout: 5000
```

## Senior Level

### Giới hạn của Starter

Các starter có thể kéo theo các transitive dependency không cần thiết. Nếu bạn cần một classpath tối thiểu (GraalVM Native Image) — dùng `<exclusions>` hoặc thêm các dependency thủ công.

### Tạo Starter của riêng bạn

```java
// Trong module autoconfigure:
@AutoConfiguration
@ConditionalOnClass(MyService.class)
@ConditionalOnMissingBean(MyService.class)
public class MyLibAutoConfiguration {

    @Bean
    public MyService myService() {
        return new MyService();
    }
}

// Spring Boot 2.7+: META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports
// Trước 2.7: META-INF/spring.factories
com.example.MyLibAutoConfiguration
```

### ConfigurationProperties

```java
@ConfigurationProperties("mylib")
public class MyLibProperties {
    private boolean enabled = true;
    private int timeout = 5000;
}

-> IDE tự động gợi ý từ spring-configuration-metadata.json
```

### Hỗ trợ Native Image

```
Spring Boot 3 + GraalVM:
  -> Các file hint cho reflection
  -> Biên dịch AOT
  -> Starter nên hỗ trợ Native Image
```

### Kinh nghiệm Production

**Tình huống thực tế: starter nội bộ công ty**
```
50 microservice -> cùng một cấu hình logging
-> Tạo mycompany-logging-starter
-> Tất cả các service có một định dạng log thống nhất
```

### Best Practices

1. **Tách** các module autoconfigure và starter
2. **@ConditionalOnMissingBean** -> cho phép ghi đè
3. **Đặt tên** -> *-spring-boot-starter cho bên thứ ba
4. **BOM** -> quản lý version
5. **ConfigurationProperties** -> cấu hình YAML
6. **Native Image** -> hỗ trợ GraalVM

### Tóm tắt cho Senior

- **Starter** = dependency + auto-configuration
- **BOM** -> các version tương thích
- **@ConditionalOnMissingBean** -> ghi đè
- **Đặt tên** -> *-spring-boot-starter cho bên thứ ba
- **ConfigurationProperties** -> cấu hình YAML
- **Native Image** -> hỗ trợ trong Spring Boot 3

## Interview Cheat Sheet

**Cần phải biết:**
- Starter = một dependency thay vì nhiều transitive dependency
- spring-boot-dependencies (BOM) cố định version của tất cả các thư viện — không "Jar Hell"
- Starter = module autoconfigure (@ConditionalOnClass, @Bean) + các dependency
- @ConditionalOnMissingBean cho phép người dùng ghi đè các bean
- Starter bên thứ ba đặt tên *-spring-boot-starter, chính thức — spring-boot-starter-*
- ConfigurationProperties cho cấu hình YAML và IDE tự động gợi ý
- Starter của riêng bạn: @AutoConfiguration + META-INF/spring/...AutoConfiguration.imports (Spring Boot 2.7+)

**Các câu hỏi phụ thường gặp:**
- *Làm sao tạo starter của riêng bạn?* — Module autoconfigure với @AutoConfiguration + đăng ký trong AutoConfiguration.imports.
- *Tại sao cần BOM?* — Cố định các version tương thích của hàng trăm thư viện qua dependencyManagement.
- *Có thể ghi đè một bean từ một starter không?* — Có, qua @ConditionalOnMissingBean — bean của bạn thay thế cái mặc định.
- *Làm gì với các transitive dependency không cần thiết?* — Dùng <exclusions> trong Maven hoặc tự lắp classpath thủ công cho GraalVM.

**Dấu hiệu cảnh báo (Red flags — KHÔNG nên nói):**
- "Starter chỉ là một jar chứa các dependency" — không, còn có auto-configuration nữa.
- "Có thể đặt tên starter của bạn là spring-boot-starter-*" — được dành riêng cho các starter chính thức.
- "BOM là một dependency thông thường" — không, nó là dependencyManagement cho các version.
- "Các starter hoạt động không cần auto-configuration" — không có nó, nó chỉ là một bộ dependency.
